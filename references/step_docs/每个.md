# 每个

- 模块键: `sys:each`
- 步骤类型: `Loop`
- 说明: 对列表的每项执行处理
- 帮助: https://getquicker.net/KC/Help/Doc/each

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:each",
  "InputParams": {
    "input": {
      "VarKey": "",
      "Value": "item1\\nitem2"
    },
    "useMultiThread": {
      "VarKey": "",
      "Value": "0"
    },
    "progressBarTitle": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "threadDelay": {
      "VarKey": "",
      "Value": "5"
    },
    "concurrentThreadNum": {
      "VarKey": "",
      "Value": "4"
    },
    "timeoutMs": {
      "VarKey": "",
      "Value": "-1"
    },
    "useLocalContext": {
      "VarKey": "",
      "Value": "false"
    },
    "waitAny": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "item": "out_item",
    "count": "out_count",
    "isSuccess": "out_isSuccess"
  },
  "IfSteps": []
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| input | 列表 | List | 是 |  |  | 要处理的列表 |
| useMultiThread | 线程模式 | Enum | 否 | 0 | 0=单线程（顺序执行） / 1=多线程（同时执行） | ⚠通常不要选择! 请阅读文档详细了解后再使用。 |
| progressBarTitle | 进度条标题 | Text | 否 |  | 仅用于 0 | 如果设置了此参数，则在循环过程中会显示一个进度条，标题为此参数的值。仅单线程支持。 |
| threadDelay | 线程启动间隔 | Integer | 否 | 5 | 仅用于 1 | 多线程运行时，每个线程之间的启动时间间隔毫秒数。 |
| concurrentThreadNum | 同时线程数 | Integer | 否 | 4 | 仅用于 1 | 最多同时启动的线程数，请根据电脑配置和任务内容设置。 |
| timeoutMs | 超时毫秒数 | Integer | 否 | -1 | 仅用于 1 | 所有线程开启后，等待的超时时间，单位：毫秒。-1:不设置超时时间 |
| useLocalContext | 为线程创建独立上下文 | Boolean | 否 | false | 仅用于 1 | 此时只能读取变量，不能更新变量（词典、列表等引用传递的除外） |
| waitAny | WaitAny模式 | Boolean | 否 | false | 仅用于 1 | 任意一个线程结束即可。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| item | 项 | Any |  | 列表中的每项，每次循环赋予当前项的值。在子步骤中应该对本输出进行处理。 |
| count | 计数 | Integer |  | 本次循环，处理到了第几项。 |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `useMultiThread`。先定控制参数，再看其余参数是否生效。
- 此步骤带子步骤体。子步骤列表直接写在 `IfSteps`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
