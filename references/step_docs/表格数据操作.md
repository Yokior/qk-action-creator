# 表格数据操作

- 模块键: `sys:tableoperation`
- 步骤类型: `Action`
- 说明: 表格变量的相关处理操作
- 帮助: https://getquicker.net/KC/Help/Doc/tableoperation

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| table | 表格变量 | Table | 是 |  |  | 要操作的表格变量 |
| type | 操作类型 | Enum | 否 | info | info=获取信息 / addRow=添加行 / update=更新行 / manage=查看或编辑数据 / select=查询或筛选行(Select) / clear=清除所有行 / deleteRows=删除符合条件的行 / deleteColumns=删除列 / importCsv=从CSV文本加载数据 / importJson=从Json文本加载数据 / importExcel=从Excel工作表加载数据 / export_text=导出文本数据 / exportExcel=导出Excel文件 |  |
| rowData | 行数据 | Dict | 否 |  | 仅用于 addRow, update | 包含行数据的词典；更新行时，仅包含要更新的列的内容。 |
| useColumnTitle | 使用列标题而非列名作为导出数据的标题 |  | 否 | false |  |  |
| excelFilePath | Excel文件路径 | Text | 否 |  | 仅用于 importExcel, exportExcel |  |
| csvDelimiter |  | Integer | 是 |  | 仅用于 importExcel |  |
| isReadOnly | CSV分隔符 | Text | 否 | , | 仅用于 export_text, importCsv | 导出或导入CSV数据时使用的字段分隔符。使用‘\\t’表示Tab。 |
|  |  | Boolean | 否 | true | 仅用于 importCsv, importJson | 加载数据之前是否清除现有的行数据 |
| sheetName | Excel工作表名 |  | 否 |  |  | 如果未指定，则取第一个工作表。工作表首行为标题行。 |
| deleteColumns | 要删除的列 | Text | 否 |  | 仅用于 deleteColumns | 可选。逗号','或分号';'隔开的列名，“*”表示删除所有列，“!列1,列2...”表示保留指定的列，删除其余的。 |
| exportColumns | 导出的列 | Text | 否 |  | 仅用于 exportExcel, export_text | 可选。逗号','或分号';'隔开的列名。留空时导出所有列。 |
| filterExpression | 筛选表达式 | Text | 否 |  | 仅用于 select, exportExcel, export_text, deleteRows, update |  |
|  |  | Boolean | 否 |  | 仅用于 manage |  |
| windowTitle | 窗口标题 | Text | 否 | 表格数据 | 仅用于 manage |  |
| helpText | 帮助文本 | Text | 否 |  | 仅用于 manage |  |
| startRowNum | 标题行号 | Boolean | 否 | 1 | 仅用于 exportExcel, export_text | CSV/Json格式的文本内容 |
| winSize | 窗口尺寸/位置 | Text | 否 |  | 仅用于 manage | 设置选择窗口的最大尺寸，格式为：宽度,高度。支持像素数值或屏幕宽高百分比，详情请参考模块文档。 |
| topMost | 是否置顶显示 | Boolean | 否 | false | 仅用于 manage | 是否置顶显示窗口 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| isConfirmed | 是否确认 | Boolean | 仅用于 manage | 是否点击了确认按钮 |
| rows | 行列表 | Object | 仅用于 select, info | 符合条件的行的数组 |
| firstRow | 第一行/结果行 | Object | 仅用于 select, addRow | 第一个符合条件的行或新添加的行，可输出为词典对象 |
| selectedRows | 选择的行列表 | Object | 仅用于 manage | 选择的所有行的列表 |
| columns | 列的列表 | Object | 仅用于 info | 表格的列的信息列表(DataTable.Columns) |
| csvExportData | CSV格式文本 | Text | 仅用于 export_text |  |
| jsonExportData | Json格式文本 | Text | 仅用于 export_text |  |
| affectedRowCount | 影响行数 | Integer | 仅用于 exportExcel, export_text, deleteRows, update | 更新或删除、筛选的行数 |
| rowCount | 行数 | Integer |  | 表格内的数据行数 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
