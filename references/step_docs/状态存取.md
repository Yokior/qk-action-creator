# 状态存取

- 模块键: `sys:stateStorage`
- 步骤类型: `Action`
- 说明: 存取状态数据；更新动作的徽标文字；设置附加的动作右键菜单项
- 帮助: https://getquicker.net/KC/Help/Doc/stateStorage

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:stateStorage",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "readActionState"
    },
    "key": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "value": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "inputIfEmpty": {
      "VarKey": "",
      "Value": "false"
    },
    "prompt": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "badgeText": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "badgeColor": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "badgeTextColor": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "actionContextMenu": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "overlayIcon": {
      "VarKey": "",
      "Value": "示例文本"
    }
  },
  "OutputParams": {
    "value": "out_value",
    "isEmpty": "out_isEmpty"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 操作类型 | Enum | 是 | readActionState | readActionState=读取动作状态 / saveActionState=写入动作状态 / UpdateActionBadge=设置徽标文字 / UpdateOverlyIcon=设置徽标图标 / UpdateContextMenu=设置附加的右键菜单项 / readGlobalState=【谨慎使用】读取全局状态 / saveGlobalState=【谨慎使用】写入全局状态 |  |
| key | 名称 | Text | 否 |  | 仅用于 readActionState, saveActionState, readGlobalState, saveGlobalState | 存储或读取的状态条目名称。 |
| value | 值 | Text | 否 |  | 仅用于 saveActionState, saveGlobalState | 要保存的状态值。使用“*NULL*”删除此状态的存储。 |
| inputIfEmpty | 为空时请用户输入 | Boolean | 否 | false | 仅用于 readActionState, readGlobalState | 如果读到的状态值为空，则弹出对话框请用户输入值。启用此选项时，请保持默认值为空。 |
| prompt | 用户输入提示 | Text | 否 |  | 仅用于 readActionState, readGlobalState |  |
| badgeText | 徽标文字 | Text | 否 |  | 仅用于 UpdateActionBadge | 在动作右上角显示的提示文字 |
| badgeColor | 徽标颜色 | Text | 否 |  | 仅用于 UpdateActionBadge | 在动作右上角显示的徽标底色。留空表示透明。 |
| badgeTextColor | 徽标文字颜色 | Text | 否 |  | 仅用于 UpdateActionBadge |  |
| actionContextMenu | 附加的右键菜单项 | Text | 否 |  | 仅用于 UpdateContextMenu | 附加的动作右键菜单，格式请参考文档 |
| overlayIcon | 徽标图标 | Text | 否 |  | 仅用于 UpdateOverlyIcon | 使用内置矢量图标：“fa:图标名称:图标颜色”。如：“fa:Solid_Circle:#FF0000” |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| value | 值 | Any | 仅用于 readActionState, readGlobalState | 读取到的值 |
| isEmpty | 是否为空 | Boolean | 仅用于 readActionState, readGlobalState | 读取到的值是否为空 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
