# 读取文件

- 模块键: `sys:readFile`
- 步骤类型: `Action`
- 说明: 将读取的文本或图片内容写入变量。
- 帮助: https://getquicker.net/KC/Help/Doc/readFile

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:readFile",
  "InputParams": {
    "path": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "type": {
      "VarKey": "",
      "Value": "text"
    },
    "encoding": {
      "VarKey": "",
      "Value": "Encoding.UTF8.WebName"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "txt": "out_txt",
    "image": "out_image",
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| path | 文件路径 | Text | 是 |  |  | 要读取的文件的完整路径。 |
| type | 格式 | Enum | 是 | text | text=文本 / image=图片 | 文件内容类型 |
| encoding | 文件编码 | Enum | 是 | Encoding.UTF8.WebName | auto=自动；仅用于 text | 文件的编码格式 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| txt | 文本内容 | Text | 仅用于 text | 读取的文本文件的内容 |
| image | 图片内容 | Image | 仅用于 image | 读取的图片文件的内容 |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
