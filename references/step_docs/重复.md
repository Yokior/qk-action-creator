# 重复

- 模块键: `sys:repeat`
- 步骤类型: `Loop`
- 说明: 循环指定的次数，或符合某个条件时中止
- 帮助: https://getquicker.net/KC/Help/Doc/repeat

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:repeat",
  "InputParams": {
    "count": {
      "VarKey": "",
      "Value": "1"
    },
    "stopCondition": {
      "VarKey": "",
      "Value": false
    },
    "startIndex": {
      "VarKey": "",
      "Value": "0"
    },
    "repeatDelayMs": {
      "VarKey": "",
      "Value": "1"
    },
    "progressBarTitle": {
      "VarKey": "",
      "Value": "示例文本"
    }
  },
  "OutputParams": {
    "count": "out_count"
  },
  "IfSteps": []
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| count | 次数 | Integer | 否 | 1 |  | 重复次数，除非符合条件提前中止。-1表示无限循环。 |
| stopCondition | 中止条件 | Boolean | 否 |  |  | 选填。条件满足时停止循环（每次循环开始时检查）。 |
| startIndex | 计数开始值 | Integer | 否 | 0 |  | 计数序号的开始值，通常应该为0。 |
| repeatDelayMs | 循环间隔时间 | Integer | 否 | 1 |  | 每次循环之间的间隔毫秒数。如果为0，请确保循环内部有其他等待步骤，避免连续循环占用较多资源。 |
| progressBarTitle | 进度条标题 | Text | 否 |  |  | 如果设置了此参数，则在循环过程中会显示一个进度条，标题为此参数的值。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| count | 计数 | Integer |  | 计数序号，表示第几次循环。 |

## 要点
- 此步骤带子步骤体。子步骤列表直接写在 `IfSteps`。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
