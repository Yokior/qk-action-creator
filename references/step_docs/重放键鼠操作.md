# 重放键鼠操作

- 模块键: `sys:playRecords`
- 步骤类型: `Action`
- 说明: 重放录制好的键鼠操作数据。
- 帮助: https://getquicker.net/KC/Help/Doc/playrecord

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:playRecords",
  "InputParams": {
    "data": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "speed": {
      "VarKey": "",
      "Value": "2"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| data | 录制数据 | Text | 是 |  |  | 录制的键鼠操作数据 |
| speed | 重放速度 | Number | 是 | 2 |  | 重放操作的速度 |

## 输出参数
无。

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
