# 提示消息

- 模块键: `sys:notify`
- 步骤类型: `Action`
- 说明: 显示可以自动消失的消息提示。
- 帮助: https://getquicker.net/KC/Help/Doc/notify

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:notify",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "Info"
    },
    "msg": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "maxLines": {
      "VarKey": "",
      "Value": "0"
    },
    "style": {
      "VarKey": "",
      "Value": "Default"
    },
    "clickAction": {
      "VarKey": "",
      "Value": "示例文本"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | Info | Success=成功 / Info=信息 / Warning=告警 / Error=错误 / WindowsToast=Windows 通知 (win10+) | 消息的类型 |
| msg | 消息内容 | Text | 是 |  |  | 显示的消息内容 |
| maxLines | 最大行数 | Integer | 是 | 0 |  | 显示内容的最大行数，0表示不限 |
| style | 风格 | Enum | 是 | Default | Default=默认（显示在屏幕底部） / Style2=风格2（显示在屏幕右侧） |  |
| clickAction | 点击命令 | Text | 否 |  | 仅用于 Default | 点击时运行命令（如网址等可以在Win+R中执行的文本，仅支持默认风格提示）。默认为复制提示文字。 |

## 输出参数
无。

## 要点
- 控制参数: `style`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
