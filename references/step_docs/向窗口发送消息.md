# 向窗口发送消息

- 模块键: `sys:sendMessage`
- 步骤类型: `Action`
- 说明: 使用SendMessage Win32Api向窗口发送消息。使用方法请搜索SendMessage Win32 API接口。
- 帮助: https://getquicker.net/KC/Help/Doc/sendMessage

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:sendMessage",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "SendMessage"
    },
    "hWnd": {
      "VarKey": "",
      "Value": 0
    },
    "wMsg": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "wParam": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "lParam": {
      "VarKey": "",
      "Value": "0"
    },
    "textLParam": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "rtn": "out_rtn"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 否 | SendMessage | SendMessage=SendMessage(等待返回，LParam为数字) / SendMessageTextLParam=SendMessage(等待返回，LParam为文本) / PostMessage=PostMessage(不等待返回) |  |
| hWnd | 窗口句柄hWnd | Integer | 否 |  |  | 留空或0表示前台窗口 |
| wMsg | 消息 | Text | 否 |  |  | 要发送的消息。 |
| wParam | wParam参数 | Text | 否 |  |  |  |
| lParam | lParam参数 | Text | 否 | 0 | 不用于 SendMessageTextLParam |  |
| textLParam | lParam参数(文本) | Text | 否 |  | 仅用于 SendMessageTextLParam | 文本内容 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| rtn | 返回值 | Integer | 仅用于 SendMessage, SendMessageTextLParam | 返回值，依据消息的不同具有不同的含义，请查询对应API的文档。 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
