# 拆分文本为列表

- 模块键: `sys:splitString`
- 步骤类型: `Action`
- 说明: 将文本拆分为列表
- 帮助: https://getquicker.net/KC/Help/Doc/splitstring

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:splitString",
  "InputParams": {
    "data": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "separator": {
      "VarKey": "",
      "Value": ","
    },
    "escapeSeparator": {
      "VarKey": "",
      "Value": "false"
    },
    "multiSeparator": {
      "VarKey": "",
      "Value": "false"
    },
    "removeEmpty": {
      "VarKey": "",
      "Value": "true"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| data | 输入 | Text | 是 |  |  | 要拆分为列表的文本 |
| separator | 分隔 | Text | 是 | , |  | 拆分分隔符 |
| escapeSeparator | 转义分隔符 | Boolean | 否 | false |  | 转义分隔符\\r\\n\\t字符 |
| multiSeparator | 使用多个分隔符拆分列表 | Boolean | 否 | false |  | 每行指定一个。 |
| removeEmpty | 滤除空值 | Boolean | 是 | true |  | 滤除没有内容的文本 |

## 输出参数
无。

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
