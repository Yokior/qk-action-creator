# 录制键鼠操作

- 模块键: `sys:record`
- 步骤类型: `Action`
- 说明: 录制键鼠操作过程
- 帮助: https://getquicker.net/KC/Help/Doc/record

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:record",
  "InputParams": {
    "autoStart": {
      "VarKey": "",
      "Value": "true"
    },
    "recordMouseMove": {
      "VarKey": "",
      "Value": "true"
    },
    "prepareSeconds": {
      "VarKey": "",
      "Value": "2"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "output": "out_output"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| autoStart | 自动开始录制 | Boolean | 否 | true |  | 2秒后是否自动开始录制 |
| recordMouseMove | 录制鼠标移动过程 | Boolean | 否 | true |  | 是否录制鼠标的中间移动过程，仅必要时开启。关闭时仅记录点击位置。 |
| prepareSeconds | 准备时间 | Number | 否 | 2 |  | 开始录制前的倒计时秒数（支持小数） |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| output | 录制数据 | Text |  | 录制的结果数据 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
