# 加密/解密/哈希

- 模块键: `sys:enc`
- 步骤类型: `Action`
- 说明: 加密、解密，以及哈希计算
- 帮助: https://getquicker.net/KC/Help/Doc/enc

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 否 | hash_hmac | enc_des=DES 加密 / dec_des=DES 解密 / enc_aes=AES 加密 / dec_aes=AES 解密 / enc_rsa=RSA 加密 / dec_rsa=RSA 解密 / hash_hmac=键控哈希 HMAC / hash=哈希（MD5、SHA1等） / local_enc=自用加密 / local_dec=自用解密 |  |
| ivContentType | 初始化向量IV内容类型 | Enum | 否 | text |  |  |
| cipherMode | 运算模式 | Text | 是 | CipherMode.CBC | 仅用于 dec_aes, enc_aes, dec_des, enc_des |  |
| key | 填充模式 | Text | 是 | PaddingMode.PKCS7 | 仅用于 dec_aes, enc_aes, dec_des, enc_des |  |
| inputContentType | 输入内容类型 | Enum | 否 | text |  |  |
| input | 输入 | Text | 是 |  |  | 待加密或解密的内容 |
| pairKey | 公钥/私钥 | Text | 是 |  | 仅用于 enc_rsa, dec_rsa | XML格式的公钥（加密用）或私钥（解密用） |
| keyContentType | 密钥内容类型 | Enum | 否 | text | 仅用于 dec_des, dec_aes, enc_aes, enc_des, hash_hmac |  |
| hashType | 算法 | Text | 否 | MD5 | 仅用于 dec_des, dec_aes, enc_aes, enc_des, hash_hmac |  |
| iv | 初始化向量 | Text | 是 | HMACSHA1 | HMACSHA1=HMACSHA1 / HMACSHA256=HMACSHA256 / HMACSHA384=HMACSHA384 / HMACSHA512=HMACSHA512 / MACTripleDES=MACTripleDES / HMACMD5=HMACMD5；仅用于 dec_des, dec_aes, enc_aes, enc_des |  |
| paddingMode |  |  | 否 |  |  |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| resultBase64 | Base64编码结果 | Text |  |  |
| resultHex | 十六进制编码(大写) | Text |  |  |
| resultLowerHex | 十六进制编码(小写) | Text |  |  |
| resultText | 文本结果 | Text | 仅用于 dec_aes, dec_des, dec_rsa, local_dec |  |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
