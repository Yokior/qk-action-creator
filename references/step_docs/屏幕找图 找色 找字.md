# 屏幕找图/找色/找字

- 模块键: `sys:searchBmp`
- 步骤类型: `Action`
- 说明: 在屏幕上查找图片里的内容出现的位置
- 帮助: https://getquicker.net/KC/Help/Doc/searchBmp

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | locateByBitmapFile | locateByBitmapFile=查找图片(文件) / locateByBitmapVar=查找图片(变量) / locateByColor=查找颜色 / locateByText=查找文字 | 操作类型 |
| color | 颜色 | Text | 否 |  | 仅用于 locateByBitmapFile | 要查找的颜色，如#FF0000 |
| bmp | 文字 | Text | 否 |  | 仅用于 locateByText | 要查找的文字。可使用多行指定多组可选文字，找到任意一组即可。 |
| bmpVar | 位图变量 | Text | 是 | #FF0000 | 仅用于 locateByColor | 需要在屏幕中查找的位图。位图必须和屏幕图像完全匹配，不能压缩。此时X、Y的值为相对于搜索位图的左上角的偏移。 |
| bmpTargetType | 查找范围 | Enum | 否 | Bxbkq1PHzY6S8TEFy8xt.MainScreen | 仅用于 locateByBitmapFile, locateByBitmapVar, locateByColor, locateByText | 位图查找范围 |
| searchRect | 查找坐标范围 | Text | 否 |  |  | 可选。当“查找范围”为“坐标范围”时有效，格式为：left,top,right,bottom |
| bmpPosition | 定位位置 | Enum | 否 | Center | Center=位图中间 / TopLeft=左上角 / TopRight=右上角 / BottomLeft=左下角 / BottomRight=右下角；仅用于 locateByBitmapFile, locateByBitmapVar | 定位点相对位图的位置 |
| x | X偏移 | Integer | 是 | 0 |  | 定位点水平坐标偏移量（正值向右） |
| y | Y偏移 | Integer | 是 | 0 |  | 定位点垂直坐标偏移量（正值向下） |
| bmpColorError | 颜色容差 | Integer | 否 | 10 | 仅用于 locateByBitmapFile, locateByBitmapVar, locateByColor | 匹配像素时允许每个颜色通道的偏差值0-100，0表示精确匹配，速度最快。 |
| maxFindCount | 最大匹配 | Integer | 否 | 1 | 仅用于 locateByBitmapFile, locateByBitmapVar | 找图的最大匹配数量。将对每个查找到的目标执行附加动作。 |
| retryCount | 重试次数 | Integer | 否 | 0 | 仅用于 locateByBitmapFile, locateByBitmapVar, locateByColor, locateByText | 未找到位图时的重试次数。每次重试间隔300ms。 |
| ignoreWindowsOcr | 跳过WindowsOCR引擎 | Boolean | 否 | false | 仅用于 locateByText |  |
| ignoreBgColor | 忽略背景色 | Boolean | 否 | true | 仅用于 locateByBitmapFile, locateByBitmapVar | 如果查找图片的4个顶点颜色一致，则认为是背景色，找图时忽略此颜色。 |
| stopIfFail | 失败后中止动作 | Boolean | 否 | true |  | 获取位置失败后，是否停止后续动作的执行。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  |  |
| firstPoint | 第一个匹配点 | Text |  | 第一个匹配点坐标，格式为：x坐标,y坐标 |
| allPoints | 所有匹配点 | List | 仅用于 locateByBitmapFile, locateByBitmapVar, locateByText | 所有的匹配点列表 |
| imgIndex | 匹配序号 | Integer | 仅用于 locateByBitmapFile, locateByText | 从多个图片或多组文字中查找时，返回匹配到的图片或文字组序号，从0开始。 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
