# 词典操作

- 模块键: `sys:dictOperations`
- 步骤类型: `Action`
- 说明: 对词典变量进行添加、删除等操作
- 帮助: https://getquicker.net/KC/Help/Doc/dictoperations

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:dictOperations",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "setOriginValue"
    },
    "dict": {
      "VarKey": "",
      "Value": "{}"
    },
    "value": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "key": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "returnEmptyIfKeyNotExist": {
      "VarKey": "",
      "Value": "false"
    },
    "ignoreCase": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "false"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 操作类型 | Enum | 否 | setOriginValue | get=取值 / set=设置值 (文本类型) / setOriginValue=设置值 (变量原始类型) / remove=删除一项 / clear=清空 / keyList=获取键(Key)列表 / valueList=获取值列表 / reverse=翻转键值 / queryStringToDict=查询字符串转换为词典(name1=value1&name2=value2...) / dictToQueryString=词典转换为查询字符串 / dictToQueryStringNoEncode=词典转换为查询字符串(不对键和值进行URL编码) |  |
| dict | 词典 | Dict | 否 |  | 不用于 queryStringToDict | 要操作的词典变量 |
| value | 忽略键的大小写 | Text | 否 |  | 仅用于 queryStringToDict |  |
| key | 键 | Text | 否 |  | 仅用于 get, set, remove, setOriginValue | 要操作元素的键值。 |
| returnEmptyIfKeyNotExist | 键不存在时返回空值 | Boolean | 否 | false | 仅用于 get | 此时不作为失败处理 |
| ignoreCase |  |  | 否 | false | 仅用于 set, get, remove, setOriginValue |  |
| stopIfFail | 失败后停止 | Boolean | 否 | false |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
