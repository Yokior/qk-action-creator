# 等待按键

- 模块键: `sys:waitKeyboard`
- 步骤类型: `Action`
- 说明: 等待用户按下某个按键
- 帮助: https://getquicker.net/KC/Help/Doc/waitkeyboard

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:waitKeyboard",
  "InputParams": {
    "waitingKeys": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "modifierKeys": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "maxWaitSeconds": {
      "VarKey": "",
      "Value": "0"
    },
    "filterEvent": {
      "VarKey": "",
      "Value": "true"
    },
    "waitKeyUp": {
      "VarKey": "",
      "Value": "false"
    },
    "ignoreSimulated": {
      "VarKey": "",
      "Value": "false"
    },
    "help": {
      "VarKey": "",
      "Value": "请按键..."
    },
    "fontfamily": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "winLocation": {
      "VarKey": "",
      "Value": "ShowWindowLocation.TopCenter"
    },
    "mouseThrough": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "keyCode": "out_keyCode",
    "keyValue": "out_keyValue",
    "holdTimeMs": "out_holdTimeMs"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| waitingKeys | 等待的按键 | Text | 否 |  |  | 可选，留空表示任意键盘按键。格式请参考文档。 |
| modifierKeys | 修饰键 | Text | 否 |  |  | 可选。逗号分隔的ctrl,shift,alt,win组合。仅用于等待组合快捷键。修饰键不会被拦截。 |
| maxWaitSeconds | 最长等待秒数 | Number | 是 | 0 |  | 0为永久超时超过等待时间，则结束等待。 |
| filterEvent | 拦截原始按键事件 | Boolean | 否 | true |  | 避免按键输入到窗口中 (仅对键盘按键有效) |
| waitKeyUp | 等待按键抬起 | Boolean | 否 | false |  | 等待按键抬起后再返回 (仅对键盘按键有效) |
| ignoreSimulated | 忽略模拟的按键 | Boolean | 否 | false |  | 是否忽略（不检测）模拟的按键消息 |
| help | 提示信息 | Text | 否 | 请按键... |  | 等待按键时显示的提示文字 |
| fontfamily | 字体名称 | Text | 否 |  |  | 可选。设置字体名称。如有多个字体，使用逗号分隔。 |
| winLocation | 提示窗口位置 | Enum | 否 | ShowWindowLocation.TopCenter |  | 在哪里显示提示窗口 |
| mouseThrough | 鼠标穿透 | Boolean | 否 | true |  | 鼠标是否可以穿透提示窗口点击下面的内容 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| keyCode | 键名 | Text |  | 按键名，具体请参考模块文档。 |
| keyValue | 键值 | Integer |  | 按键数值，具体请参考模块文档。 |
| holdTimeMs | 按下保持时间 | Integer |  | 按下保持时间，单位毫秒。仅支持键盘按键。 |

## 要点
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
