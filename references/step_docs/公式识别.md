# 公式识别

- 模块键: `sys:mathocr`
- 步骤类型: `Action`
- 说明: 数学公式识别
- 帮助: https://getquicker.net/KC/Help/Doc/mathocr

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:mathocr",
  "InputParams": {
    "vendor": {
      "VarKey": "",
      "Value": "Vendors.Mathpix"
    },
    "image": {
      "VarKey": "",
      "Value": ""
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "mathpixMarkdown": "out_mathpixMarkdown",
    "latex": "out_latex",
    "mathml": "out_mathml",
    "asciimath": "out_asciimath",
    "latexEx1": "out_latexEx1",
    "latexEx2": "out_latexEx2",
    "rawData": "out_rawData"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| vendor | 厂商接口 | Enum | 否 | Vendors.Mathpix |  | 详情请参考文档。 |
| image | 公式图片 | Image | 是 |  |  | 指定待识别的图片变量、图片文件的路径或网址(通过表达式传入)。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| mathpixMarkdown | Mathpix MD | Text |  | Mathpix Markdown格式 |
| latex | Latex | Text |  |  |
| mathml | MathML | Text |  |  |
| asciimath | AsciiMath | Text |  |  |
| latexEx1 | Latex附加格式1 | Text |  |  |
| latexEx2 | Latex附加格式2 | Text |  |  |
| rawData | 原始响应 | Text |  | 厂商接口返回的原始内容，通常为json格式。 |

## 要点
- 控制参数: `vendor`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
