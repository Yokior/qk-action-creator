# 多字段表单

- 模块键: `sys:form`
- 步骤类型: `Action`
- 说明: 使用表单窗口编辑多个变量的值。
- 帮助: https://getquicker.net/KC/Help/Doc/form

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 工作模式 | Enum | 否 | variables | variables=编辑动作变量的值 / dict=编辑词典数据 / dict_dynamic=编辑词典数据（动态） | 工作模式：编辑某个词典的值，或编辑一些变量的值 |
| dictVar | 词典变量 | Dict | 否 |  | 仅用于 dict, dict_dynamic | 表单需要编辑的词典变量 |
| title | 窗口标题 | Text | 是 | 填写表单 |  | 表单窗口标题文字 |
| formDef | 表单定义 | Form | 是 |  | 仅用于 variables |  |
| formForDictDef | 表单定义(词典) | FormForDict | 是 |  | 仅用于 dict |  |
| dynamicFormForDictDef | 表单定义(词典) | Text | 是 |  | 仅用于 dict_dynamic | JSON格式的表单定义数据。格式说明请参考模块文档。 |
| help | 提示文字 | Text | 否 |  |  | 帮助用户填写表单的提示文字。 |
| markdownhelp | 帮助按钮内容 | Text | 否 |  |  | 点击弹出显示帮助内容，MarkDown格式。 |
| titleColumnWidth | 标题列宽度 | Number | 否 | 100 |  | 左侧字段标题区域的宽度(逻辑像素)。负值，如-200表示自适应列宽且最大宽度为200。 |
| windowWidth | 窗口宽度 | Number | 是 | 500 |  | 逻辑像素，最小400。 |
| defaultInputWidth | 输入框默认宽度 | Number | 是 | 0 |  | 逻辑像素，0表示自动宽度。 |
| windowHeight | 窗口最大高度 | Number | 是 | 0 |  | 逻辑像素，0表示默认。设置时请填写大于100的值。 |
| restoreFocus | 恢复活动窗口 | Boolean | 否 | false |  | 用户输入后，是否将焦点还原到之前的活动窗口 |
| topMost | 置顶显示 | Boolean | 否 | false |  |  |
| confirm | 自定义“确定”按钮标题 | Text | 否 |  |  | 仅在需要时填写。使用\"_字符\"的形式定义触发字符,如\"_S\"表示Alt+S可直接触发按钮 |
| customButtons | 自定义按钮 | Text | 否 |  |  | 使用\"标题|返回值\"的形式定义按钮，多个按钮用换行分隔。 |
| selectedGroup | 选择的分组 | Text | 否 |  |  | 使用分组标签页时，默认选择的分组。 |
| winSize | 位置 | Text | 否 |  |  | 当 “窗口位置” 类型为 “自定义位置” 时用于指定显示位置，格式为：left,top,right,bottom |
| disableEnterSubmit | 关闭Enter提交表单功能 | Boolean | 否 | false |  |  |
| stopIfFail | 取消后停止 | Boolean | 否 | true |  | 取消后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| button | 点击的按钮 | Text |  | 默认的确认按钮返回值为空，自定义按钮返回值为自定义的值。 |
| selectedGroup | 选择的分组 | Text |  | 关闭时所选择的标签页分组。 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
