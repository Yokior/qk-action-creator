# 注释

- 模块键: `sys:comment`
- 步骤类型: `Comment`
- 说明: 使用注释将步骤分组，描述后续步骤的目的。
- 帮助: https://getquicker.net/KC/Help/Doc/comment

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:comment",
  "InputParams": {
    "note": {
      "VarKey": "",
      "Value": "示例文本"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| note | 注释内容 | Text | 否 |  |  | 注释内容 |

## 输出参数
无。

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
