# 运行或打开

- 模块键: `sys:run`
- 步骤类型: `Action`
- 说明: 运行软件或命令，打开文件、文件夹或网址。效果类似于在Windows“运行”对话框中执行命令。
- 帮助: https://getquicker.net/KC/Help/Doc/run

    },

      "VarKey": "",

    },

      "VarKey": "",

    },

      "VarKey": "",

    },

      "VarKey": "",

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| path | 路径或命令 | Text | 是 |  |  | 要运行的命令或打开的文件路径、网址、URI等。 |
| arg | 参数(可选) | Text | 否 |  |  | 程序参数 |
| setWorkingDir | 工作目录 | Text | 否 | 1 |  | 可输入 0或留空(不设置,由windows默认)、1(软件所在目录)、具体的工作目录路径。 |
| windowStyle | 窗口风格 | Enum | 否 | 0 | 0=普通(Normal) / 1=隐藏(Hidden) / 2=最小化(Minimized) / 3=最大化(Maximized) | 设置期望的窗口风格，是否有效依赖于具体的软件。 |
| runas | 以管理员身份运行 | Boolean | 否 | false |  | 以管理员身份运行软件或命令。 |
| waitInputIdle | 等待启动完成 | Boolean | 否 | false |  | 等待进程完成后了初始化，可以接受用户输入。 |
| waitExit | 等待进程结束 | Boolean | 否 | false |  | 等待进程结束后再执行后续操作步骤。 |
| activateWindowIfRunning | 如果程序已运行则尝试激活窗口 | Boolean | 否 | false |  | 如果程序已经在运行，则尝试激活其窗口。 |
| activateWindowHotkey | 激活窗口快捷键 | Text | 否 |  |  | 对于支持快捷键激活窗口的软件，设置该快捷键。支持“模拟按键B”语法。 |
| alternativePath | 备用路径 | Text | 否 |  |  | 文件在多个电脑上路径不同时，使用备用路径填写其他电脑上的文件路径。 |
| username | 用户名 | Text | 否 |  |  | 使用指定的用户运行 |
| password | 密码 | Text | 否 |  |  | 用户名对应的密码 |
| outputEncoding | 控制台输出编码 | Enum | 是 | oem | utf8=UTF8 / oem=OEM | 控制台输出编码。如果输出遇到乱码，尝试修改此选项。 |
| envVariables | 环境变量 | Text | 否 |  |  | 为应用程序设置特定的环境变量值。每行一个，格式“变量名=值”，如“CONFIG_FILE=d:\\config.json” |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| pid | PID | Integer |  | 进程ID |
| mainWinHandle | 主窗口句柄 | Integer |  | 进程的主窗口句柄 |
| mainWinTitle | 主窗口标题 | Text |  |  |
| stdout | 控制台输出 | Text |  | 慎用！仅用于控制台程序，会自动等待进程结束。输出stdout，为空时输出stderr。 |
| stdoutOnly | stdout输出 | Text |  | 慎用！捕获控制台程序的stdout输出，会自动等待进程结束 |
| stderr | stderr输出 | Text |  | 慎用！捕获控制台程序的stderr输出，会自动等待进程结束 |
| exitCode | 退出代码 | Integer |  | 进程的ExitCode，会自动等待进程结束。 |

## 要点
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
