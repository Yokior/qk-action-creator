# 显示进度条

- 模块键: `sys:reportProgress`
- 步骤类型: `Action`
- 说明: 显示/更新进度条
- 帮助: https://getquicker.net/KC/Help/Doc/reportProgress

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:reportProgress",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "REQUEST_ID"
    },
    "progressId": {
      "VarKey": "",
      "Value": "0"
    },
    "title": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "percentage": {
      "VarKey": "",
      "Value": "0"
    },
    "text": {
      "VarKey": "",
      "Value": "示例文本"
    }
  },
  "OutputParams": {
    "progressId": "out_progressId"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | REQUEST_ID | REQUEST_ID=创建进度条 / UPDATE_PROGRESS=更新进度 / REMOVE=去除进度条 | 操作类型 |
| progressId | 进度条ID | Integer | 否 | 0 | 仅用于 UPDATE_PROGRESS, REMOVE | 进度条的序号，用于后续更新或删除进度条 |
| title | 进度条标题 | Text | 否 |  | 仅用于 UPDATE_PROGRESS | 进度条的标题(显示在进度条上方) |
| percentage | 进度百分比 | Number | 否 | 0 | 仅用于 UPDATE_PROGRESS | 0到100之间的数字 |
| text | 说明文字 | Text | 否 |  | 仅用于 UPDATE_PROGRESS | 显示在进度条下方 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| progressId | 进度条ID | Integer | 仅用于 REQUEST_ID | 进度条的序号，用于后续更新或删除进度条 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
