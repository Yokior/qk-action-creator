# 按键操作

- 模块键: `sys:keyoperation`
- 步骤类型: `Action`
- 说明: 单个键盘按键的操作控制或状态获取
- 帮助: https://getquicker.net/KC/Help/Doc/keyoperation

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:keyoperation",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "get_key_state"
    },
    "key": {
      "VarKey": "",
      "Value": ""
    },
    "keepMs": {
      "VarKey": "",
      "Value": "1000"
    }
  },
  "OutputParams": {
    "isDown": "out_isDown",
    "isToggled": "out_isToggled"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 否 | get_key_state | get_key_state=获取按键状态 / key_down=按下按键 / key_up=抬起按键 / key_keydown_v1=按下Quicker虚拟键V1 / key_keyup_v1=抬起Quicker虚拟键V1 | 操作类型。按下和抬起需要配对使用。 |
|  |  |  | 否 |  | 不用于 key_keydown_v1, key_keyup_v1 |  |
| key |  |  | 否 |  |  |  |
| keepMs | 保持按下时间 | Integer | 否 | 1000 | 仅用于 key_keydown_v1 | 保持此虚拟键按下的时间（毫秒数），之后会自动抬起。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isDown | 是否按下 | Boolean | 仅用于 get_key_state | 此按键是否为按下状态 |
| isToggled | 是否锁定 | Boolean | 仅用于 get_key_state | 此按键是否为锁定状态，仅对CapsLock、NumLock等按键有效。 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
