# 如果/否则

- 模块键: `sys:if`
- 步骤类型: `If`
- 说明: 依据条件执行操作
- 帮助: https://getquicker.net/KC/Help/Doc/if

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:if",
  "InputParams": {
    "condition": {
      "VarKey": "",
      "Value": false
    }
  },
  "IfSteps": [],
  "ElseSteps": []
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| condition | 如果 | Boolean | 否 |  |  | 是否符合指定的条件 |

## 输出参数
无。

## 要点
- 此步骤带分支体。`IfSteps` 为条件成立步骤列表，`ElseSteps` 为否则步骤列表。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
