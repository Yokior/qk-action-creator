# 输入法状态

- 模块键: `sys:imeControl`
- 步骤类型: `Action`
- 说明: 获取或更改当前的输入法中英文状态，避免在发送热键时受影响。
- 帮助: https://getquicker.net/KC/Help/Doc/imecontrol

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:imeControl",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "GET_STATE"
    }
  },
  "OutputParams": {
    "isEnabled": "out_isEnabled"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 是 | GET_STATE | ENABLE=切换为中文 / DISABLE=切换为英文 / RESTORE=恢复 / GET_STATE=是否为中文状态？ | 要执行的操作。所有操作仅在输入法启用的情况下有效。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isEnabled | 是否为中文状态 | Boolean | 仅用于 GET_STATE |  |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
