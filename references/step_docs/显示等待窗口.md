# 显示等待窗口

- 模块键: `sys:showWaitWin`
- 步骤类型: `Action`
- 说明: 显示一个等待用户完成某个操作的提示窗口。
- 帮助: https://getquicker.net/KC/Help/Doc/showwaitwin

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:showWaitWin",
  "InputParams": {
    "stopActionIfClose": {
      "VarKey": "",
      "Value": ""
    },
    "title": {
      "VarKey": "",
      "Value": "完成后继续"
    },
    "prompt": {
      "VarKey": "",
      "Value": "请在完成操作后点下面的按钮"
    },
    "iconSize": {
      "VarKey": "",
      "Value": ""
    },
    "operations": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "fontsize": {
      "VarKey": "",
      "Value": "12"
    },
    "mode": {
      "VarKey": "",
      "Value": "16"
    },
    "progress": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "btnText": {
      "VarKey": "",
      "Value": "完成"
    },
    "help": {
      "VarKey": "",
      "Value": "示例文本"
    }
  },
  "OutputParams": {
    "isClosed": "out_isClosed",
    "selectedOperation": "out_selectedOperation"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| stopActionIfClose |  |  | 否 |  |  |  |
| title | 窗口标题 | Text | 是 | 完成后继续 | 仅用于 show, update, showAndWaitClose |  |
| prompt | 提示文字 | Text | 是 | 请在完成操作后点下面的按钮 | 仅用于 show, update, showAndWaitClose | 提示文字内容 |
| iconSize | 图标大小 |  | 否 |  |  | 按钮上图标的大小，单位为逻辑像素。 |
| operations | 附加操作按钮 | Text | 是 |  | 仅用于 show, update, showAndWaitClose | 每行定义一个按钮，格式为 “文本” 或 “显示文本|值”。显示在默认按钮的左侧。 |
| fontsize | 文字大小 | Number | 是 | 12 | 仅用于 show, update, showAndWaitClose | 按钮上文字的大小，单位为逻辑像素。 |
| mode | 关闭窗口时（点右上角x按钮）后停止动作 | Number | 是 | 16 | show=显示窗口 / update=更新窗口 / check=检查是否关闭 / close=关闭窗口(如果还开着的话) / waitClose=等待用户关闭 / showAndWaitClose=显示窗口并等待用户关闭；仅用于 show, update, showAndWaitClose | 请选择操作类型 |
| progress | 进度条参数 | Text | 否 |  | 仅用于 show, showAndWaitClose | 请以 当前值/总数 的格式传入（可使用插值方式）。 比如：40/80 |
| btnText | 默认按钮上的文字 | Boolean | 是 | 完成 | 仅用于 show, showAndWaitClose | 默认按键仅用于关闭窗口。文字内容为空时隐藏默认按钮。 |
|  |  |  | 否 | NotActivatable | NotActivatable=不支持激活（不占用焦点，仅能使用鼠标操作） / NotActivated=支持激活，打开时不抢占焦点 / AutoActivate=支持激活，打开时抢占焦点；仅用于 show, showAndWaitClose |  |
| help | 帮助按钮内容 | Text | 否 |  | 仅用于 show, showAndWaitClose | 点击弹出显示帮助内容，MarkDown格式 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isClosed | 是否已关闭 | Boolean | 仅用于 check | 等待窗口是否已经关闭了 |
| selectedOperation | 选择的按钮 | Text | 仅用于 check, waitClose, showAndWaitClose | 选择的后续操作项 |

## 要点
- 控制参数: `mode`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
