# 步骤组

- 模块键: `sys:group`
- 步骤类型: `Loop`
- 说明: 一组有关的模块（方便整体禁用、删除等）
- 帮助: https://getquicker.net/KC/Help/Doc/group

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:group",
  "InputParams": {
    "skipErr": {
      "VarKey": "",
      "Value": "false"
    },
    "skipWhenDebugging": {
      "VarKey": "",
      "Value": "false"
    },
    "useMultiThread": {
      "VarKey": "",
      "Value": "false"
    },
    "waitAny": {
      "VarKey": "",
      "Value": "false"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "errorMessage": "out_errorMessage"
  },
  "IfSteps": []
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| skipErr | 忽略错误 | Boolean | 否 | false |  | 忽略内部步骤的错误，继续允许后续代码 |
| skipWhenDebugging | 调试运行时不输出调试内容 | Boolean | 否 | false |  | 用以减少不必要的调试输出 |
| useMultiThread | 使用多线程 | Boolean | 否 | false |  | ⚠通常不要选择! 请阅读文档详细了解后再使用。 |
| waitAny | 多线程使用WaitAny模式 | Boolean | 否 | false |  | 任意一个线程结束即可。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 内部步骤是否运行成功 |
| errorMessage | 错误消息 | Text |  |  |

## 要点
- 此步骤带子步骤体。子步骤列表直接写在 `IfSteps`。
- 适合按“阶段”组织主流程，例如“预备”“获取输入”“生成结果”“收尾”。
- 适合包裹一整段只调用一次、但步骤较多的逻辑，用来提升折叠性和可读性。
- 组名、用途说明优先写到步骤的 `Note`，不要留成空块。
- 如果一段逻辑未来可能复用，不要只放在步骤组里，优先进一步抽成子程序。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
