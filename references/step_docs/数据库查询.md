# 数据库查询

- 模块键: `sys:dboperation`
- 步骤类型: `Action`
- 说明: 对数据库执行SQL语句并返回结果
- 帮助: https://getquicker.net/KC/Help/Doc/dboperation

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:dboperation",
  "InputParams": {
    "dbType": {
      "VarKey": "",
      "Value": "sqlserver"
    },
    "connectionString": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "sql": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "sqlParam": {
      "VarKey": "",
      "Value": ""
    },
    "timeoutSeconds": {
      "VarKey": "",
      "Value": 0
    },
    "operationType": {
      "VarKey": "",
      "Value": "Query"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "rowsAffected": "out_rowsAffected",
    "scalarResult": "out_scalarResult",
    "dataTableResult": "out_dataTableResult",
    "listResult": "out_listResult",
    "firstItem": "out_firstItem",
    "rowCount": "out_rowCount"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| dbType | 数据库连接类型 | Enum | 否 |  | sqlserver=SQL Server / mysql=MySQL / sqlite=SQLite / oledb=OleDB / odbc=ODBC |  |
| connectionString | 连接字符串 | Text | 否 |  |  | Connection string |
| sql | SQL语句 | Text | 否 |  |  | 要执行的SQL语句内容 |
| sqlParam | 参数 | Object | 否 |  |  | 为SQL语句提供的参数 |
| timeoutSeconds | 超时秒数 | Integer | 否 |  |  | 留空或0表示默认。 |
| operationType | 执行方式 | Enum | 否 | Query | Query=Query：查询并返回结果数据 / Execute=Execute：执行并返回影响的行数 / ExecuteScalar=ExecuteScalar：执行并返回单个值(首行首列的值) |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| rowsAffected | 影响行数 | Integer | 仅用于 Execute |  |
| scalarResult | 单值结果 | Any | 仅用于 ExecuteScalar |  |
| dataTableResult | 查询结果(表格) | Table | 仅用于 Query | 获取表格类型的行结果 |
| listResult | 查询结果(对象列表) | Object | 仅用于 Query | 获得动态对象列表类型的结果 |
| firstItem | 首项结果 | Object | 仅用于 Query | 如果只需要返回结果的第一行，可以使用此项输出，支持词典或dynamic对象。没有结果时返回null。 |
| rowCount | 结果行数 | Integer | 仅用于 Query |  |

## 要点
- 控制参数: `operationType`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
