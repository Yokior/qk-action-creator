# 比较数字

- 模块键: `sys:numCompare`
- 步骤类型: `Action`
- 说明: 比较数字大小。
- 帮助: https://getquicker.net/KC/Help/Doc/numcompare

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:numCompare",
  "InputParams": {
    "param1": {
      "VarKey": "",
      "Value": "0"
    },
    "type": {
      "VarKey": "",
      "Value": ">"
    },
    "param2": {
      "VarKey": "",
      "Value": "0"
    }
  },
  "OutputParams": {
    "value": "out_value"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| param1 | 数字1 | Number | 是 | 0 |  | 左侧的数字 |
| type | 类型 | Enum | 是 | > |  | 比较方式 |
| param2 | 数字2 | Number | 是 | 0 |  | 右侧的数字 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| value | 值 | Boolean |  | 比较结果是否为真 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
