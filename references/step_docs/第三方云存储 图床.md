# 第三方云存储/图床

- 模块键: `sys:cloud_oss`
- 步骤类型: `Action`
- 说明: 使用第三方云服务上传文件。
- 帮助: https://getquicker.net/KC/Help/Doc/cloud_oss

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:cloud_oss",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "Upload"
    },
    "vendor": {
      "VarKey": "",
      "Value": "Aliyun"
    },
    "vendorSettings": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "key": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "content": {
      "VarKey": "",
      "Value": ""
    },
    "customDomain": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "extraHeaders": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "expireSeconds": {
      "VarKey": "",
      "Value": "180"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "vendorUrl": "out_vendorUrl",
    "customUrl": "out_customUrl",
    "err": "out_err"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 是 | Upload | Upload=上传 |  |
| vendor | 服务商 | Enum | 是 | Aliyun | Aliyun=阿里云 OSS / Tencent=腾讯云 COS / Qiniu=七牛云 |  |
| vendorSettings | 服务商参数 | Text | 是 |  |  | 设置相关 |
| key | 对象名 | Text | 否 |  | 仅用于 Upload | 可选。留空时自动生成对象名。如果以'/'结尾，则在此基础上自动生成对象名。 |
| content | 上传内容 | Any | 否 |  | 仅用于 Upload | 要上传的文件路径、其它文本内容或图片变量。 |
| customDomain | 自定义域名 | Text | 否 |  | 仅用于 Upload | 如“https://files.example.com”。 |
| extraHeaders | 额外的请求头 | Text | 是 |  |  | 可选。设置厂商相关的特定http头。 |
| expireSeconds | 超时时间 | Number | 否 | 180 |  | 请求超时时间（秒数） |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| vendorUrl | 服务商网址 | Any | 仅用于 Upload |  |
| customUrl | 自定义域名网址 | Any | 仅用于 Upload | 设置了自定义域名时会生成此网址。 |
| err | 错误信息 | Text |  | 出错时输出的错误信息。 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
