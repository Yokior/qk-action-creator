# 显示图片

- 模块键: `sys:showImage`
- 步骤类型: `Action`
- 说明: 在屏幕上显示图片。输入文件路径/url或图片变量。
- 帮助: https://getquicker.net/KC/Help/Doc/showImage

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| source | 操作/来源 | Enum | 否 | var | file=显示：图片文件或网络图片 / var=显示：变量中的图片 / clipboard=显示：剪贴板图片 / closeWindow=关闭图片窗口 / getState=获取图片窗口信息 / getImageWindows=获取所有图片窗口标识 | 图片来源类型 |
| path | 路径/网址 | Text | 是 |  | 仅用于 file | 图片文件的路径或网址。 |
| imgVar | 图片变量 | Image | 是 |  | 仅用于 var | 从指定变量中加载图片 |
| scale | 初始缩放比例 | Number | 是 | 1 | 仅用于 file, var, clipboard | 可以为小数，1表示原始大小，-1表示对大图自动调整缩放比例 |
| opacity | 不透明度 | Number | 是 | 1 | 仅用于 file, var, clipboard | 0-1之间的小数，1为完全不透明，0为完全透明。 |
| autoCloseKey | 唯一性标识 | Text | 否 |  | 仅用于 file, var, clipboard, closeWindow, getState | (仅必要时使用)自动关闭之前打开的具有此标识的图片窗口。 |
| autoCloseTime | 自动关闭时间 | Number | 是 | 0 | 仅用于 file, var, clipboard | 几秒后自动关闭，可以为小数。0：不自动关闭。 |
| winLocation | 显示位置 | Enum | 否 | ShowWindowLocation.Auto | 仅用于 file, var, clipboard | 图片显示位置 |
| winPosition | 位置坐标 | Text | 否 |  | 仅用于 file, var, clipboard | 仅用于位置为“自定义位置”类型。格式为:left,top或left,top,right,bottom |
| waitClose | 等待图片关闭 | Boolean | 否 | false | 仅用于 file, var, clipboard | 是否等待图片关闭后再执行后续步骤 |
| showDropShadow | 显示阴影 | Boolean | 否 | true | 仅用于 file, var, clipboard | 是否显示边框阴影 |
| showTaskbarIcon | 显示任务栏图标 | Boolean | 否 | true | 仅用于 file, var, clipboard | 是否显示任务栏图标 |
| topMost | 是否置顶显示 | Boolean | 否 | true | 仅用于 file, var, clipboard | 是否置顶显示图片 |
| noActivate | 不激活窗口 | Boolean | 否 | false | 仅用于 file, var, clipboard | 图片窗口显示时不抢占焦点（无法通过Esc关闭） |
| closeWhenLostFocus | 丢失焦点时自动关闭 | Boolean | 否 | false | 仅用于 file, var, clipboard |  |
| tooltip | ToolTip提示文字 | Text | 否 |  | 仅用于 file, var, clipboard |  |
| closeCallbackParam | 关闭窗口回调参数 | Text | 否 |  | 仅用于 file, var, clipboard | 关闭图片窗口时，运行当前动作，并传入指定参数。未指定参数时，不进行回调。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isExists | 是否存在 | Boolean | 仅用于 getState | 是否存在指定标识的窗口 |
| hwnd | 窗口句柄 | Integer | 仅用于 file, var, clipboard, getState | 新创建的图片窗口的句柄 |
| finalPosition | 最终贴图位置 | Text | 仅用于 file, var, clipboard, getState | 移动窗口后的贴图位置格式为left,top,right,bottom。显示图片（开启“等待图片关闭” 选项）或获取当前打开的图片窗口信息时有效。 |
| windowIdList | 窗口标识列表 | List | 仅用于 getImageWindows |  |

## 要点
- 控制参数: `source`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
