# 组合成文本

- 模块键: `sys:formatString`
- 步骤类型: `Action`
- 说明: 将（多个）变量组合成一段文本。
- 帮助: https://getquicker.net/KC/Help/Doc/formatstring

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:formatString",
  "InputParams": {
    "formatString": {
      "VarKey": "",
      "Value": "{0}"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| formatString | 格式化字符串 | Text | 是 | {0} |  | 使用C#的String.Format语法。 |

## 输出参数
无。

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
