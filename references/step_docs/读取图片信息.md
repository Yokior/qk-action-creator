# 读取图片信息

- 模块键: `sys:imageinfo`
- 步骤类型: `Action`
- 说明: 获取图片的尺寸或exif信息
- 帮助: https://getquicker.net/KC/Help/Doc/imageinfo

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:imageinfo",
  "InputParams": {
    "sourceType": {
      "VarKey": "",
      "Value": "var"
    },
    "bmpFile": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "bmpVar": {
      "VarKey": "",
      "Value": ""
    },
    "autoRotate": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "width": "out_width",
    "height": "out_height",
    "rotateDegree": "out_rotateDegree",
    "dateTimeOriginal": "out_dateTimeOriginal",
    "exifData": "out_exifData",
    "rawExifData": "out_rawExifData"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| sourceType | 图片来源 | Enum | 否 | var | var=图片变量 / file=图片文件 |  |
| bmpFile | 文件路径 | Text | 是 |  | 仅用于 file | 图片文件的完整路径 |
| bmpVar | 图片变量 | Image | 是 |  | 仅用于 var |  |
| autoRotate | 计算旋转后的宽高 | Boolean | 否 | false |  | 如果Exif中包含旋转角度信息，则获取旋转后的宽高 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| width | 宽度 | Integer |  |  |
| height | 高度 | Integer |  |  |
| rotateDegree | 旋转角度 | Integer |  |  |
| dateTimeOriginal | 拍摄时间 | DateTime |  |  |
| exifData | Exif数据 | Dict |  | 转换为文本格式的exif数据（词典格式，请参考模块文档） |
| rawExifData | 原始属性数据 | Dict |  | 原始Exif数据(词典格式，请参考模块文档) |

## 要点
- 控制参数: `sourceType`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
