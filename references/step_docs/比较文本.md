# 比较文本

- 模块键: `sys:strCompare`
- 步骤类型: `Action`
- 说明: 文本比较
- 帮助: https://getquicker.net/KC/Help/Doc/strCompare

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:strCompare",
  "InputParams": {
    "param1": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "type": {
      "VarKey": "",
      "Value": ">"
    },
    "param2": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "case": {
      "VarKey": "",
      "Value": "false"
    }
  },
  "OutputParams": {
    "value": "out_value"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| param1 | 文本1 | Text | 是 |  |  | 被比较的文本 |
| type | 类型 | Enum | 是 | > | contains=包含 / startsWith=以指定内容开始 / endsWith=以指定内容结束 / match=正则匹配 / pinyinMatch=包含指定内容，或匹配拼音、拼音首字母 | 比较方式 |
| param2 | 文本2 | Text | 是 |  |  | 对比文本。拼音匹配时，也可用于指定拼音、拼音首字母。 |
| case | 区分大小写 | Boolean | 否 | false | 不用于 pinyinMatch | 是否区分大小写 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| value | 值 | Boolean |  | 比较结果是否为真 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
