# 临时图床

- 模块键: `sys:tempImgBed`
- 步骤类型: `Action`
- 说明: 将图片上传到临时（1分钟后删除）的图床，用以搜图等场景。勿上传非法内容。
- 帮助: https://getquicker.net/KC/Help/Doc/tempImgBed

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:tempImgBed",
  "InputParams": {
    "imgVar": {
      "VarKey": "",
      "Value": ""
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "url": "out_url"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| imgVar | 图片变量 | Image | 否 |  |  | 指定要上传的图片变量。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| url | 网址 | Text |  | 图片的临时网址 |

## 要点
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
