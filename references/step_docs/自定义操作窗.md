# 自定义操作窗

- 模块键: `sys:custompanel`
- 步骤类型: `Action`
- 说明: 显示或控制自定义操作窗。
- 帮助: https://getquicker.net/KC/Help/Doc/custompanel

## 先记结论

- 控制参数实际是 `operation`，不是 `saveState`。
- `saveState` 是单独的布尔开关，用来记忆位置、尺寸、分组等状态。
- `operationData` 支持文本格式、JSON 格式、`CommonOperationItem` 对象。
- 需要稳定生成动作时，默认优先用 JSON 格式描述 `operationData`。
- `horzAlign` 实际用 `Left` / `Center` / `Right`，不是数字。
- 常见显示操作是：
  - `show_fixed_panel`
  - `show_fixed_panel_wait_close`
  - `close_fixed_panel`
  - `toggle_collapse`
  - `get_panel_info`
- 关闭窗口只需要 `operation + windowId`。

## 输入参数

| Key | 名称 | 类型 | 必填 | 适用操作 | 说明 |
| --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 是 | 全部 | 控制参数 |
| operationData | 操作项定义 | Text | 是 | `show_fixed_panel` / `show_fixed_panel_wait_close` | 操作项数据 |
| defaultOperation | 默认操作 | Text | 否 | `show_fixed_panel` / `show_fixed_panel_wait_close` | 主要用于文本简写模式 |
| spacingStr | 按钮间距 | Text | 否 | 显示窗口 | 常见值如 `5`、`10,6` |
| buttonPadding | 按钮内边距 | Text | 否 | 显示窗口 | 如 `5`、`10,6`、`7,8,9,10` |
| columnCount | 列数 | Integer | 否 | 显示窗口 | `0` 表示自动 |
| columnWidth | 列宽 | Integer | 否 | 显示窗口 | `0` 自动，`-1` 不对齐 |
| groupMode | 分组方式 | Enum | 否 | 显示窗口 | `heading` / `expander` / `tab-top` / `tab-left` / `tab-right` / `tab-bottom` / `headingLeft` / `columns` / `none` |
| title | 标题 | Text | 否 | 显示窗口 | 窗口标题 |
| windowId | 窗口标识 | Text | 是 | 全部 | 常用 `=` 表示当前动作 |
| winLocation | 窗口位置 | Enum | 否 | 显示窗口 | 如 `CenterScreen`、`WithMouse1` |
| winSize | 窗口尺寸或位置 | Text | 否 | 显示窗口 | 宽高或自定义坐标 |
| saveState | 记忆状态 | Boolean | 否 | 显示窗口 | `1` / `0` |
| horzAlign | 按钮内容对齐 | Enum | 否 | 显示窗口 | `Left` / `Center` / `Right` |
| bgColor | 背景颜色 | Text | 否 | 显示窗口 | 颜色文本 |
| btnColor | 按钮颜色 | Text | 否 | 显示窗口 | 颜色文本 |
| btnBorderColor | 按钮边框颜色 | Text | 否 | 显示窗口 | 颜色文本 |
| fontColor | 字体颜色 | Text | 否 | 显示窗口 | 颜色文本 |
| fontsize | 字体大小 | Number | 否 | 显示窗口 | 如 `12` |
| iconsize | 图标大小 | Number | 否 | 显示窗口 | 如 `16` |
| buttonContextMenuData | 按钮右键菜单 | Text | 否 | 显示窗口 | 给按钮附加菜单 |
| contextMenuData | 窗口右键菜单 | Text | 否 | 显示窗口 | 给窗口附加菜单 |
| bindProc | 关联进程 | Text | 否 | 显示窗口 | 进程前台时显示 |
| autoCollapse | 自动折叠 | Enum | 否 | 显示窗口 | `0` / `1` / `-1` |
| stopIfFail | 失败后停止 | Boolean | 否 | 全部 | 失败后是否停止动作 |

## 输出参数

| Key | 名称 | 类型 | 适用操作 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean | 全部 | 操作是否成功 |
| selectedItemData | 选择的操作项数据 | Text | `show_fixed_panel_wait_close` | 点中的项本身的 `Data` |
| selectedItem | 选择的操作项 | Object | `show_fixed_panel_wait_close` | 点中的 `CommonOperationItem` |
| currentGroup | 当前分组 | Object | `show_fixed_panel_wait_close` / `get_panel_info` | 标签页或分组信息 |
| isWindowVisible | 窗口是否可见 | Boolean | `get_panel_info` | 可能因关联进程而隐藏 |
| isWindowExpanded | 窗口是否展开 | Boolean | `get_panel_info` | 当前展开状态 |
| winHandle | 窗口句柄 | Integer | `show_fixed_panel` / `get_panel_info` | 窗口句柄 |
| buttonItemData | 按钮操作项数据 | Text | `show_fixed_panel_wait_close` | 当点击的是按钮菜单项时，对应按钮本身的 `Data` |
| buttonItem | 按钮操作项 | Object | `show_fixed_panel_wait_close` | 当点击的是按钮菜单项时，对应按钮本身的 `CommonOperationItem` |

## CommonOperationItem 最小字段

默认可按下面结构生成：

```json
{
  "Title": "打开记事本",
  "Icon": "fa:Regular_FileAlt",
  "Description": "",
  "Data": "notepad.exe",
  "DataType": null,
  "Operation": "run",
  "Action": "",
  "IsSeparator": false,
  "OriginText": null,
  "Menu": null,
  "SecondaryIcon": null,
  "SpName": "",
  "ExtraData": {},
  "Children": []
}
```

常用字段：

- `Title`：显示标题。
- `Icon`：图标，通常用 `fa:`。
- `Data`：主要业务数据。
- `Operation`：点击后执行类型，如 `run`、`sp`。
- `SpName`：当 `Operation = "sp"` 时的子程序名。
- `Menu`：按钮右侧菜单项列表。
- `Children`：分组子项列表。
- `ExtraData`：附加业务字段。

## operationData 两种稳定写法

### 1. JSON 形式

推荐。最稳定。

```json
[
  {
    "Title": "打开记事本",
    "Icon": "fa:Regular_FileAlt",
    "Description": "",
    "Data": "notepad.exe",
    "DataType": null,
    "Operation": "run",
    "Action": "",
    "IsSeparator": false,
    "OriginText": null,
    "Menu": null,
    "SecondaryIcon": null,
    "SpName": "",
    "ExtraData": {},
    "Children": []
  }
]
```

### 2. 文本形式

只在文档已明确、需求简单时使用。

```text
[fa:Regular_FileAlt]打开记事本|notepad.exe
[fa:Regular_Folder]打开下载目录|D:\Downloads
```

注意：

- 这种简写依赖 `defaultOperation`。
- 目前本 skill 只确认“依赖它”这一点。
- 若你不能明确写出 `defaultOperation` 的值，就不要用文本形式，改用 JSON。

## 返回值怎么理解

- 点击普通按钮：
  - `selectedItemData` = 当前按钮的 `Data`
  - `buttonItemData` 为空
- 点击按钮上的菜单项：
  - `selectedItemData` = 被点击菜单项的 `Data`
  - `buttonItemData` = 这个菜单所属按钮本身的 `Data`
- 若只是 `show_fixed_panel`，通常不等待用户选择，因此不依赖这两个返回值。

## 生成规则

- 默认优先生成 `operationData` JSON。
- 需要等待用户选择结果时，用 `show_fixed_panel_wait_close`。
- 需要常驻面板时，用 `show_fixed_panel`。
- 需要单独关闭时，再补一个 `close_fixed_panel` 步骤。
- `windowId` 默认优先写 `=`。
- `horzAlign` 只写 `Left` / `Center` / `Right`。
- `saveState` 只当布尔开关理解，不把它当控制参数。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
