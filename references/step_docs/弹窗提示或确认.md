# 弹窗提示或确认

- 模块键: `sys:MsgBox`
- 步骤类型: `Action`
- 说明: 弹窗显示提示或确认对话框
- 帮助: https://getquicker.net/KC/Help/Doc/msgbox

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:MsgBox",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "default"
    },
    "message": {
      "VarKey": "",
      "Value": "Hello."
    },
    "title": {
      "VarKey": "",
      "Value": "Quicker"
    },
    "buttons": {
      "VarKey": "",
      "Value": "OK"
    },
    "customButtons": {
      "VarKey": "",
      "Value": "[fa:Regular_Check:#4caf50]是(_Y)|Yes\\r\\n[fa:Regular_Times:#dc3545]否(_N)|No\\r\\n[fa:Light_Undo:#444444]取消(_C)|Cancel"
    },
    "restoreFocus": {
      "VarKey": "",
      "Value": "true"
    },
    "defaultButton": {
      "VarKey": "",
      "Value": "Yes"
    }
  },
  "OutputParams": {
    "result": "out_result",
    "okOrYes": "out_okOrYes"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 模式 | Enum | 否 | default | default=标准 / custom=自定义 |  |
| message | 消息内容 | Text | 是 | Hello. |  | 弹窗显示的消息内容。“自定义”模式时，也支持“MD:Markdown内容”。 |
| title | 标题 | Text | 是 | Quicker |  | 消息窗口标题。留空时自动使用动作名称。 |
| buttons | 按钮 | Enum | 是 | OK | 仅用于 default | 消息窗口图标 |
| customButtons | 按钮 | Text | 是 | [fa:Regular_Check:#4caf50]是(_Y)|Yes\r\n[fa:Regular_Times:#dc3545]否(_N)|No\r\n[fa:Light_Undo:#444444]取消(_C)|Cancel | 仅用于 custom | 每行定义一个按钮，格式为 “文本” 或 “[图标]显示文本(提示内容)|值”。 |
| restoreFocus | 恢复活动窗口 | Boolean | 否 | true |  | 关闭弹窗后，是否将焦点还原到之前的活动窗口 |
| defaultButton | 默认按钮 | Text | 是 | Yes | 仅用于 custom | 指定默认按钮的值。默认按钮以高亮颜色显示，可直接回车选择。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| result | 选择的按钮 | Text |  | 点击的按钮，标准模式下结果可能为OK,Cancel,Yes,No，自定义模式下为按钮的值。 |
| okOrYes | 是否确认 | Boolean | 仅用于 default | 选择的按钮是否为“确定”或“是” |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
