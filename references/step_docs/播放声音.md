# 播放声音

- 模块键: `sys:playSound`
- 步骤类型: `Action`
- 说明: 播放声音提示或声音文件。
- 帮助: https://getquicker.net/KC/Help/Doc/playsound

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:playSound",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "LOCAL"
    },
    "text": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "wait": {
      "VarKey": "",
      "Value": false
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 否 | LOCAL | LOCAL=内置声音提示 / EXTERN=电脑文件或网络文件 / TTS=朗读文本（系统TTS） |  |
|  |  | Text | 否 |  | 仅用于 EXTERN |  |
| text | 文本内容 | Text | 否 |  | 仅用于 TTS | 需要朗读的文本。 |
| wait | 等待播放完成 | Boolean | 否 |  |  |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
