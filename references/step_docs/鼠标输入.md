# 鼠标输入

- 模块键: `sys:mouse`
- 步骤类型: `Action`
- 说明: 模拟鼠标输入
- 帮助: https://getquicker.net/KC/Help/Doc/mouse

    },

      "Value": ""
    },
    "bmpTargetType": {

    },

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | restore | restore=还原鼠标位置 / move=移动距离 / moveTo=移动到(x,y分别指定) / moveToXy=移动到(x,y一同指定) / click=单击 / dbclick=双击 / down=按下 / up=抬起 / scroll=滚动 / ctrlDown=按下Ctrl / ctrlUp=松开Ctrl / shiftDown=按下Shift / shiftUp=松开Shift / toWinTL=移动到窗口位置：相对于窗口左上角 / toWinTR=移动到窗口位置：相对于窗口右上角 / toWinBL=移动到窗口位置：相对于窗口左下角 / toWinBR=移动到窗口位置：相对于窗口右下角 / toWinCenter=移动到窗口位置：窗口中心 / moveToWinXy=移动到窗口位置：xy一同指定 / locateByBitmap=移动到位图位置(图片文件) / locateByBitmapVar=移动到位图位置(图片变量) / getMouseOriginPosition=获取鼠标位置(弹出面板前位置) / getMouseCurrentPosition=获取鼠标位置及指针类型(当前位置) / showIndicator=显示鼠标位置提示 | 操作类型 |
| btn | 按钮 | Enum | 是 | left | left=左键 / right=右键 / middle=中键 / x1=X1 / x2=X2；仅用于 click, dbclick, down, up | 操作哪个按钮 |
| hWnd | 窗口句柄 |  | 否 |  |  | 目标窗口的句柄。留空或 0 表示操作前台窗口。 |
| bmpVar | 位图变量 | Image | 是 |  | 仅用于 locateByBitmapVar | 需要在屏幕中查找的位图。位图必须和屏幕图像完全匹配，不能压缩。此时X、Y的值为相对于搜索位图的左上角的偏移。 |
| bmpTargetType | 查找范围 | Enum | 否 | MainScreen | MainScreen=主屏幕 / CurrentWindow=当前窗口 / Rect=坐标范围；仅用于 locateByBitmap, locateByBitmapVar | 位图查找范围 |
| searchRect | 查找坐标范围 | Text | 否 |  | 仅用于 locateByBitmap, locateByBitmapVar | 当“查找范围”为“坐标范围”时有效，格式为：left,top,right,bottom |
| bmpPosition | 定位位置 | Enum | 否 | Center | Center=位图中间 / TopLeft=左上角 / TopRight=右上角 / BottomLeft=左下角 / BottomRight=右下角；仅用于 locateByBitmap, locateByBitmapVar | 查找到图片后，鼠标指针移动到的位置 |
| bmpColorError | 颜色容差 | Integer | 否 | 10 | 仅用于 locateByBitmap, locateByBitmapVar | 匹配像素时允许每个颜色通道的偏差值0-100，0表示精确匹配，速度最快。 |
| maxFindCount | 最大匹配数量 | Integer | 否 | 1 | 仅用于 locateByBitmap, locateByBitmapVar | 找图的最大匹配数量。将对每个查找到的目标执行附加动作。 |
| retryCount | 重试次数 | Integer | 否 | 1 | 仅用于 locateByBitmap, locateByBitmapVar | 未找到位图时的重试次数。每次重试间隔300ms。 |
| x | X | Integer | 是 | 0 |  | 水平方向的坐标/坐标偏移/移动距离(像素) 或 滚动数量（clicks。正值向右，负值向左） |
| y | Y | Integer | 是 | 0 |  | 垂直方向的坐标/坐标偏移/移动距离 或 滚动数量（clicks。正值向前，负值向后） |
| xy | 坐标 | Text | 是 |  | 仅用于 moveToXy | 格式为：x,y，如：100,200。也可以使用百分比表示，如：50%,50% 表示屏幕中心。 |
| xyForWin | 相对坐标 | Text | 是 |  | 仅用于 moveToWinXy | 格式为：x,y，如：100,200（相对于窗口左上角向右100，向下200）。也可以使用百分比表示，如：50%,50% 表示窗口中心。 |
| slowMove | 逐渐移动到目标 | Boolean | 否 | false | 仅用于 move, moveTo, toWinTL, toWinTR, toWinBL, toWinBR, toWinCenter, locateByBitmap, locateByBitmapVar, moveToXy, moveToWinXy | 逐渐移动而不是直接移动到目标位置。 |
| extAction | 移动后操作 | Enum | 是 | none | none=无 / left=左键单击 / leftDbClick=左键双击 / right=右键单击 / middle=中键单击；仅用于 restore, move, moveTo, toWinTL, toWinTR, toWinBL, toWinBR, toWinCenter, locateByBitmap, locateByBitmapVar, moveToXy, moveToWinXy | 移动位置后，需要执行的动作 |
| restoreMousePos | 操作完成后恢复鼠标位置 | Boolean | 否 | false | 仅用于 move, moveTo, toWinTL, toWinTR, toWinBL, toWinBR, toWinCenter, locateByBitmap, locateByBitmapVar, moveToXy, moveToWinXy |  |
| stopIfFail | 失败后中止动作 | Boolean | 否 | true | 仅用于 locateByBitmap, locateByBitmapVar | 获取位置失败后，是否停止后续动作的执行。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 找图定位是否成功 | Boolean | 仅用于 locateByBitmap, locateByBitmapVar |  |
| mouseLocation | 鼠标位置 | Text | 仅用于 getMouseCurrentPosition, getMouseOriginPosition, getCaretPosition | 格式为X,Y的文本 |
| mouseX | 鼠标位置X | Integer | 仅用于 getMouseCurrentPosition, getMouseOriginPosition, getCaretPosition | 鼠标位置X坐标 |
| mouseY | 鼠标位置Y | Integer | 仅用于 getMouseCurrentPosition, getMouseOriginPosition, getCaretPosition | 鼠标位置Y坐标 |
| cursorType | 光标类型 | Text | 仅用于 getMouseCurrentPosition | 当前的鼠标指针形状类型 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
