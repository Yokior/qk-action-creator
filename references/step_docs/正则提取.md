# 正则提取

- 模块键: `sys:regexExtract`
- 步骤类型: `Action`
- 说明: 使用正则表达式提取指定内容
- 帮助: https://getquicker.net/KC/Help/Doc/regexextract

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:regexExtract",
  "InputParams": {
    "getGroup": {
      "VarKey": "",
      "Value": "0"
    },
    "data": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "pattern": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "ignoreCase": {
      "VarKey": "",
      "Value": "false"
    },
    "singleLine": {
      "VarKey": "",
      "Value": "false"
    },
    "multiLine": {
      "VarKey": "",
      "Value": "false"
    },
    "rightToLeft": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "matchObj": "out_matchObj",
    "matchesCollection": "out_matchesCollection",
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| getGroup | 提取方式 | Enum | 是 | 0 | 0=各匹配项的值 / 1=第一个匹配项的组 / 2=各匹配项的组 | 输出的内容根据提取内容有所不同，请参考模块文档。 |
| data | 输入 | Text | 是 |  |  | 要提取内容的文本 |
| pattern | 正则表达式 | Text | 是 |  |  | 用于提取内容的正则表达式 |
| ignoreCase | 忽略大小写 | Boolean | 否 | false |  | 不区分英文大小写 |
| singleLine | 单行模式 | Boolean | 否 | false |  | 此模式下“.”能匹配任意字符，包括换行符。(否则匹配除了\\n外的任意字符) |
| multiLine | 多行模式 | Boolean | 否 | false |  | 此模式下^和$可以分别匹配行首和行尾。(否则匹配输入内容的开始和结束) |
| rightToLeft | 从右向左 | Boolean | 否 | false |  | 从右向左查找匹配内容 |
| stopIfFail | 失败后中止动作 | Boolean | 否 | true |  | 操作失败后，是否停止后续动作的执行。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| matchObj | Match对象 | Object | 仅用于 1 | 首个匹配的原始的C#语言Match对象，可以在表达式中使用 |
| matchesCollection | Matches集合 | Object | 仅用于 0, 2 | 所有匹配的原始Match对象集合(MatchCollection)，可以在表达式中使用 |
| isSuccess | 是否成功 | Boolean |  | 是否匹配成功 |

## 要点
- 控制参数: `getGroup`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
