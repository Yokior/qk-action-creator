# 数字转换与处理

- 模块键: `sys:numberprocess`
- 步骤类型: `Action`
- 说明: 数字转换为文本等相关处理
- 帮助: https://getquicker.net/KC/Help/Doc/numberprocess

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:numberprocess",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "toString"
    },
    "srcNumber": {
      "VarKey": "",
      "Value": "0"
    },
    "decimalPlace": {
      "VarKey": "",
      "Value": "2"
    },
    "roundingMethod": {
      "VarKey": "",
      "Value": "Round45"
    },
    "toIntegerMethod": {
      "VarKey": "",
      "Value": "Round45"
    },
    "srcNumberStr": {
      "VarKey": "",
      "Value": "0"
    },
    "srcBase": {
      "VarKey": "",
      "Value": "0"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "rtnF": "out_rtnF",
    "rtnN": "out_rtnN",
    "rtnPercent": "out_rtnPercent",
    "rtnInteger": "out_rtnInteger",
    "resultHex": "out_resultHex",
    "resultOctal": "out_resultOctal",
    "resultBin": "out_resultBin"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作 | Enum | 否 | toString | toString=数字转换为文本 / toInteger=取整 / baseConversion=进制转换 |  |
| srcNumber | 原始数字 | Number | 否 | 0 | 仅用于 toString, toInteger |  |
| decimalPlace | 保留小数位 | Integer | 否 | 2 | 仅用于 toString |  |
| roundingMethod | 舍入方式 | Enum | 否 | Round45 | Round=舍入：奇进偶舍 / Round45=舍入：四舍五入 / Truncate=截断；仅用于 toString |  |
| toIntegerMethod | 取整方式 | Enum | 否 | Round45 | Round=舍入：奇进偶舍 / Round45=舍入：四舍五入 / Ceiling=向上取整 / Floor=向下取整；仅用于 toInteger |  |
| srcNumberStr | 原始数字(文本) | Text | 否 | 0 | 仅用于 baseConversion |  |
| srcBase | 原始数字进制 | Integer | 否 | 0 | 仅用于 baseConversion | 可选0/2/8/16。0为自动判断：全由0、1构成判断为二进制，0x开始或包含A-D判断为16进制，其它判断为10进制。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| rtnF | 结果文本(不含逗号) | Text | 仅用于 toString | 如1234.56 |
| rtnN | 结果文本(含逗号) | Text | 仅用于 toString | 如1,234.56 |
| rtnPercent | 结果文本(百分比) | Text | 仅用于 toString | 如23.56% |
| rtnInteger | 结果整数 | Integer | 仅用于 toInteger, baseConversion | 十进制数 |
| resultHex | 十六进制 | Text | 仅用于 baseConversion |  |
| resultOctal | 八进制 | Text | 仅用于 baseConversion |  |
| resultBin | 二进制 | Text | 仅用于 baseConversion |  |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
