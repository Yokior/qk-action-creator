# 机器翻译/词典

- 模块键: `sys:translation`
- 步骤类型: `Action`
- 说明: 调用第三方服务翻译文字到指定的语言。此功能需要单独付费使用，详情请参考文档。
- 帮助: https://getquicker.net/KC/Help/Doc/translation

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:translation",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "single"
    },
    "text": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "srcLang": {
      "VarKey": "",
      "Value": "CommonLanguage.Auto"
    },
    "dstLang": {
      "VarKey": "",
      "Value": "CommonLanguage.Auto"
    },
    "vendor": {
      "VarKey": "",
      "Value": "Vendors.Youdao"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "resultText": "out_resultText",
    "rawData": "out_rawData",
    "vendorResult": "out_vendorResult",
    "vendorRawData": "out_vendorRawData",
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 是 | single | single=单厂商文字翻译 / multiple=多厂商文字翻译 / en2zh_dict=英汉词典 |  |
| text | 待翻译文本内容或单词。 | Text | 否 |  |  |  |
| srcLang | 源语言 | Text | 否 | CommonLanguage.Auto | 不用于 en2zh_dict | 待翻译内容的语言 |
| dstLang | 目标语言 | Text | 否 | CommonLanguage.Auto | 不用于 en2zh_dict | 翻译的结果语言 |
| vendor | 厂商 | Enum | 否 | Vendors.Youdao | 仅用于 single | 不同厂商价格不同，详情请参考文档。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| resultText | 结果文本 | Text |  | 翻译结果文本。多厂商翻译时自动组合各厂商结果 |
| rawData | 原始响应 |  | 仅用于 single, en2zh_dict | 厂商接口返回的原始内容，通常为json格式。 |
| vendorResult | 各厂商翻译结果 | Dict | 仅用于 multiple | 各厂商的翻译结果（词典）。key为厂商标识，value为翻译结果。 |
| vendorRawData | 各厂商原始响应 | Dict | 仅用于 multiple | 各厂商的原始响应内容（词典）。key为厂商标识，value为厂商原始响应。 |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
