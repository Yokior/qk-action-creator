# 云状态存取

- 模块键: `sys:clouddata`
- 步骤类型: `Action`
- 说明: 根据键值读取或写入网络数据。
- 帮助: https://getquicker.net/KC/Help/Doc/clouddata

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:clouddata",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "readGlobalState"
    },
    "key": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "value": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "expireSeconds": {
      "VarKey": "",
      "Value": "2.5"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "value": "out_value",
    "err": "out_err"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 操作类型 | Enum | 是 | readGlobalState | readGlobalState=从网络读取数据 / saveGlobalState=写入数据到网络 |  |
| key | 状态名称 | Text | 否 |  | 仅用于 readGlobalState, saveGlobalState | 存储或读取的数据条目名称(键)。 |
| value | 内容 | Text | 否 |  | 仅用于 saveGlobalState | 要保存的数据值。使用“*NULL*”删除此状态的存储。 |
| expireSeconds | 超时时间 | Number | 否 | 2.5 |  | 请求超时时间（秒数） |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| value | 内容 | Any | 仅用于 readGlobalState | 读取到的状态内容 |
| err | 错误信息 | Text |  | 出错时输出的错误信息。 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
