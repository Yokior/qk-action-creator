# 图片处理

- 模块键: `sys:imgProcess`
- 步骤类型: `Action`
- 说明: 图片处理和变换
- 帮助: https://getquicker.net/KC/Help/Doc/imgprocess

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:imgProcess",
  "InputParams": {
    "img": {
      "VarKey": "",
      "Value": ""
    },
    "type": {
      "VarKey": "",
      "Value": "resize_percent"
    },
    "resizePercent": {
      "VarKey": "",
      "Value": "50"
    },
    "maxWidth": {
      "VarKey": "",
      "Value": "0"
    },
    "maxHeight": {
      "VarKey": "",
      "Value": "0"
    },
    "rotation": {
      "VarKey": "",
      "Value": "0"
    },
    "filterParams": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "iconFilePath": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "iconSize": {
      "VarKey": "",
      "Value": "256,48,32,16"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "result": "out_result"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| img | 图片 | Image | 是 |  |  | 要转换的图片 |
| type | 操作类型 | Enum | 否 | resize_percent | resize_percent=缩放图片(指定比例) / resize_pixel=缩小图片(指定像素) / Clone=复制图片 / Invert=反色 / GrayScale=灰度 / Rotate=旋转 / Filters=组合处理 / GenerateIco=生成图标文件(.ico) | 对图片的转换操作类型 |
| resizePercent | 缩放比例 | Number | 否 | 50 | 仅用于 resize_percent | 缩小或放大到原来的百分之多少 |
| maxWidth | 最大宽度 | Integer | 否 | 0 | 仅用于 resize_pixel | 最大宽度(像素数)，0表示自动 |
| maxHeight | 最大高度 | Integer | 否 | 0 | 仅用于 resize_pixel | 最大高度(像素数)，0表示自动 |
| rotation | 旋转方式 | Integer | 否 | 0 | 仅用于 Rotate | 顺时针角度。0:不旋转, 1:90°, 2:180°, 3:270°, 其他值请参考模块文档。 |
| filterParams | 处理参数 | Text | 否 |  | 仅用于 Filters | 每行设定一个处理步骤，具体设置请参考文档 |
| iconFilePath | 图标文件保存路径 | Text | 是 |  | 仅用于 GenerateIco | 保存图标文件(.ico)的完整路径 |
| iconSize | 图标大小 | Text | 是 | 256,48,32,16 | 仅用于 GenerateIco | 图标中的位图大小，单位为像素。多尺寸图标可用英文逗号风格 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| result | 结果图片 | Image | 仅用于 Clone, resize_percent, resize_pixel, Filters | 处理后的图片 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
