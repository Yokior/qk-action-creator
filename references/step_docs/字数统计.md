# 字数统计

- 模块键: `sys:textCounter`
- 步骤类型: `Action`
- 说明: 统计文本行数、字符数等
- 帮助: https://getquicker.net/KC/Help/Doc/textcounter

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:textCounter",
  "InputParams": {
    "content": {
      "VarKey": "",
      "Value": "示例文本"
    }
  },
  "OutputParams": {
    "line": "out_line",
    "char": "out_char",
    "visableChar": "out_visableChar",
    "cnChar": "out_cnChar"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| content | 文本 | Text | 是 |  |  | 要统计的内容 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| line | 行数 | Integer |  |  |
| char | 字符数 | Integer |  |  |
| visableChar | 可见字符数 | Integer |  |  |
| cnChar | 汉字数 | Integer |  |  |

## 要点
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
