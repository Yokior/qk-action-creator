# 临时云存储

- 模块键: `sys:tempcloudstore`
- 步骤类型: `Action`
- 说明: 将文本、文件、图片临时保存到云端并得到网址。
- 帮助: https://getquicker.net/KC/Help/Doc/tempcloudstore

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:tempcloudstore",
  "InputParams": {
    "dataType": {
      "VarKey": "",
      "Value": "text"
    },
    "text": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "imageVar": {
      "VarKey": "",
      "Value": ""
    },
    "file": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "expireSeconds": {
      "VarKey": "",
      "Value": "2.5"
    },
    "useRandomFileName": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "url": "out_url"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| dataType | 数据类型 | Enum | 是 | text | text=文本内容 / file=文件 / imageVar=图片变量 |  |
| text | 文本内容 | Text | 是 |  | 仅用于 text | 要保存的文本内容 |
| imageVar | 图片变量 | Image | 否 |  | 仅用于 imageVar | 要保存的图片变量 |
| file | 文件路径 | Text | 是 |  | 仅用于 file | 要保存的文件路径 |
| expireSeconds | 超时时间 | Number | 否 | 2.5 |  | 请求超时时间（秒数） |
| useRandomFileName | 生成随机文件名 | Boolean | 否 | false |  | 是否使用随机的文件名（仅适用于上传文件的情况） |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| url | 网址 | Text |  | 生成的访问网址 |

## 要点
- 控制参数: `dataType`。先定控制参数，再看其余参数是否生效。
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
