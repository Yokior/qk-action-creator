# 替换文本

- 模块键: `sys:strReplace`
- 步骤类型: `Action`
- 说明: 替换文本中的指定内容
- 帮助: https://getquicker.net/KC/Help/Doc/strReplace

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:strReplace",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "single"
    },
    "input": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "batchReplaceData": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "old": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "new": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "escapeOld": {
      "VarKey": "",
      "Value": "false"
    },
    "replaceEscapes": {
      "VarKey": "",
      "Value": "true"
    },
    "useRegex": {
      "VarKey": "",
      "Value": "false"
    },
    "ignoreCase": {
      "VarKey": "",
      "Value": "false"
    },
    "singleLine": {
      "VarKey": "",
      "Value": "true"
    },
    "multiLine": {
      "VarKey": "",
      "Value": "false"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 操作类型 | Enum | 是 | single | single=普通（替换一种内容） / batch=批量（替换多种内容） |  |
| input | 输入 | Text | 是 |  |  | 要提取内容的文本 |
| batchReplaceData | 查找和替换内容 | Text | 是 |  | 仅用于 batch | 每行一对查找和替换内容，中间使用|||或|分隔。例如将a替换成A，写作:a|A 或 a|||A |
| old | 查找内容 | Text | 是 |  | 仅用于 single | 要替换的内容 |
| new | 替换为 | Text | 是 |  | 仅用于 single | 替换成的内容 |
| escapeOld | 转义“查找内容” | Boolean | 否 | false |  | 替换“查找内容”中的转义字符（\\r,\\n,\\t） |
| replaceEscapes | 转义“替换为” | Boolean | 否 | true |  | 替换“替换为”中的转义字符（\\r,\\n,\\t） |
| useRegex | 使用正则替换 | Boolean | 否 | false |  |  |
| ignoreCase | 忽略大小写 | Boolean | 否 | false |  |  |
| singleLine | 正则：单行 | Boolean | 否 | true |  | 此模式下“.”能匹配任意字符，包括换行符。(否则匹配除了\\n外的任意字符) |
| multiLine | 正则：多行 | Boolean | 否 | false |  | 此模式下^和$可以分别匹配行首和行尾。(否则匹配输入内容的开始和结束) |

## 输出参数
无。

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
