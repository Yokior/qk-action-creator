# 获取选择的文件(夹)/选择特定文件

- 模块键: `sys:getSelectedFiles`
- 步骤类型: `Action`
- 说明: 获取资源管理器、桌面等位置选择的文件或文件夹的路径
- 帮助: https://getquicker.net/KC/Help/Doc/getselectedfiles

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:getSelectedFiles",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "getSelection"
    },
    "waitMs": {
      "VarKey": "",
      "Value": "200"
    },
    "sortType": {
      "VarKey": "",
      "Value": "Default"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    },
    "winHandle": {
      "VarKey": "",
      "Value": 0
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "files": "out_files",
    "firstFile": "out_firstFile",
    "fileNames": "out_fileNames",
    "firstFileName": "out_firstFileName",
    "fileCount": "out_fileCount"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 否 | getSelection | getSelection=获取选择的文件 / setSelection=设置选择的文件 |  |
| waitMs | 等待剪贴板时间 | Integer | 否 | 200 | 仅用于 getSelection | 通过复制方式获取选择文件时，等待剪贴板变化的最长时间毫秒数。 |
|  |  |  | 否 |  | Default=默认（文件名自然排序） / Origin=原始（系统返回顺序） / FileName=文件名（字母顺序） / FileNameNature=文件名（自然顺序） / FileSizeAsc=文件大小（从小到大） / FileSizeDesc=文件大小（从大到小） / CreationTimeDesc=创建时间（从新到旧） / CreationTimeAsc=创建时间（从旧到新） / LastAccessTimeDesc=最后访问时间（从晚到早） / LastAccessTimeAsc=最后访问时间（从早到晚） / LastWriteTimeDesc=最后写入时间（从晚到早） / LastWriteTimeAsc=最后写入时间（从早到晚）；仅用于 getSelection |  |
| sortType | 排序文件列表 | Text | 否 | Default | 仅用于 setSelection | 获取多个文件时，根据需要可以对文件列表进行排序。仅支持文件。 |
| stopIfFail | 失败后中止动作 | Boolean | 否 | true |  | 获取失败后，是否停止后续动作的执行。 |
| winHandle | 指定窗口句柄 | Integer | 否 |  | 仅用于 setSelection | 指定要操作的资源管理器窗口，留空时表示前台窗口。（仅支持资源管理器） |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 是否成功获得文件列表 |
| files | 路径列表 | List | 仅用于 getSelection | 所有选中的文件和文件夹的路径列表 |
| firstFile | 首个路径 | Text | 仅用于 getSelection | 选择1个文件(夹)时，返回其路径；选择多个时，返回第一个的路径。 |
| fileNames | 文件(夹)名列表 | List | 仅用于 getSelection | 所有选中的文件和文件夹的名称的列表（不包含所在路径） |
| firstFileName | 首个文件(夹)名 | Text | 仅用于 getSelection | 选择1个文件(夹)时，返回其名称；选择多个时，返回第一个的名称。 |
| fileCount | 文件个数 | Integer | 仅用于 getSelection, setSelection | 选择的文件个数 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
