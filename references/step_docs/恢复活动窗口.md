# 恢复活动窗口

- 模块键: `sys:restoreActiveWindow`
- 步骤类型: `Action`
- 说明: 如果活动窗口改变了（比如使用了参数输入步骤）,使用此动作恢复窗口焦点。
- 帮助: https://getquicker.net/KC/Help/Doc/restoreactivewindow

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:restoreActiveWindow",
  "InputParams": {}
}
```

## 输入参数
无。

## 输出参数
无。

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
