# 音频设备

- 模块键: `sys:audioControl`
- 步骤类型: `Action`
- 说明: 获取音频设备信息，设置默认音频设备。
- 帮助: https://getquicker.net/KC/Help/Doc/audioControl

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:audioControl",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "GetOutputDeviceList"
    },
    "id": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "mute": {
      "VarKey": "",
      "Value": "true"
    },
    "volume": {
      "VarKey": "",
      "Value": "0.1"
    },
    "returnAll": {
      "VarKey": "",
      "Value": "false"
    },
    "deviceName": {
      "VarKey": "",
      "Value": ""
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "deviceList": "out_deviceList",
    "deviceId": "out_deviceId",
    "deviceName": "out_deviceName",
    "deviceState": "out_deviceState",
    "mute": "out_mute",
    "isPlaying": "out_isPlaying",
    "volume": "out_volume",
    "masterPeakValue": "out_masterPeakValue",
    "deviceObject": "out_deviceObject",
    "deviceObjectList": "out_deviceObjectList"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 否 | GetOutputDeviceList | GetOutputDeviceList=获取输出设备列表 / GetOutputDefaultDevice=获取默认输出设备信息 / GetInputDeviceList=获取输入设备列表 / GetInputDefaultDevice=获取默认输入设备信息 / GetDeviceById=获取指定设备的信息 / SetDefaultDeviceById=设置默认设备 / SetDeviceMute=设置静音 / SetDeviceVolume=设置音量 |  |
| id | 设备ID | Text | 是 |  | 仅用于 GetDeviceById, SetDefaultDeviceById, SetDeviceMute, SetDeviceVolume | 要获取或更新信息的设备ID。 |
| mute | 静音状态 | Text | 是 | true | true=静音 / false=取消静音 / toggle=切换静音状态；仅用于 SetDeviceMute | 可选值 true/false/toggle 静音、取消静音或切换状态。 |
| volume | 音量 | Number | 是 | 0.1 | 仅用于 SetDeviceVolume | 0-1.0之间的小数数字。 |
| returnAll | 返回所有状态的设备 | Boolean | 否 | false | 仅用于 GetOutputDeviceList, GetInputDeviceList | 否则只返回就绪状态 (Active) 的设备 |
| deviceName | 蓝牙设备名称 |  | 否 |  | 仅用于 ConnectBluetoothDevice |  |
| stopIfFail | 失败后停止动作 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| deviceList | 设备信息列表 | List | 仅用于 GetOutputDeviceList, GetInputDeviceList | 每项的格式为:[图标]名称(注释)|设备ID |
| deviceId | 设备ID | Text | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice |  |
| deviceName | 设备名称 | Text | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById |  |
| deviceState | 设备状态 | Text | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById |  |
| mute | 是否静音 | Boolean | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById |  |
| isPlaying | 是否正在播放 | Boolean | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById |  |
| volume | 设置音量 | Number | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById |  |
| masterPeakValue | 实时音量 | Number | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById |  |
| deviceObject | 原始对象 | Object | 仅用于 GetOutputDefaultDevice, GetInputDefaultDevice, GetDeviceById | 原始MMDevice对象 |
| deviceObjectList | 原始对象列表 | Object | 仅用于 GetOutputDeviceList, GetInputDeviceList | 原始MMDevice对象的列表(IList<MMDevice>) |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
