# 获取资源管理器路径/跳转路径

- 模块键: `sys:getExplorerPath`
- 步骤类型: `Action`
- 说明: 获取资源管理器的当前文件夹路径。
- 帮助: https://getquicker.net/KC/Help/Doc/getexplorerpath

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:getExplorerPath",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "getPath"
    },
    "path": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "output": "out_output",
    "allPathList": "out_allPathList",
    "lastPath": "out_lastPath",
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 否 | getPath | getPath=获取路径 / setPath=设置路径 |  |
| path | 路径 | Text | 否 |  | 仅用于 setPath |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| output | 当前窗口路径 | Text | 仅用于 getPath | 当前资源管理器窗口的路径 |
| allPathList | 所有打开的路径 | List | 仅用于 getPath | 所有资源管理器窗口中打开的路径列表 |
| lastPath | 最近访问的路径 | Text | 仅用于 getPath | 最近访问的资源管理器窗口的路径 |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
