# 录制声音/语音识别

- 模块键: `sys:recordSound`
- 步骤类型: `Action`
- 说明: 录制音频到文件或识别语音
- 帮助: https://getquicker.net/KC/Help/Doc/recordsound

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:recordSound",
  "InputParams": {
    "vendorAccount": {
      "VarKey": "",
      "Value": "record"
    },
    "silentStopSeconds": {
      "VarKey": "",
      "Value": "16000|1"
    },
    "operation": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "waveFormat": {
      "VarKey": "",
      "Value": "0"
    },
    "filePath": {
      "VarKey": "",
      "Value": ""
    },
    "autoStartSeconds": {
      "VarKey": "",
      "Value": ""
    },
    "helpText": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "outputFilePath": "out_outputFilePath",
    "speechContent": "out_speechContent",
    "error": "out_error"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| vendorAccount | 服务商账号 | Text | 否 | record | record=录制外部声音 / record_internal=录制正在播放的声音 / short_voice_input=短语音输入 | 专业版用户可不填。格式要求请参考模块文档 |
| silentStopSeconds | 采样率和声道 | Enum | 否 | 16000|1 | 8000|1=单声道，8 kHz / 16000|1=单声道，16 kHz / 22050|1=单声道，22.05 kHz / 32000|1=单声道，32 kHz / 44100|1=单声道，44.1 kHz / 8000|2=双声道，8 kHz / 16000|2=双声道，16 kHz / 22050|2=双声道，22.05 kHz / 32000|2=双声道，32 kHz / 44100|2=双声道，44.1 kHz；仅用于 record |  |
| operation | 操作类型 | Text | 否 |  | 仅用于 record, record_internal |  |
| waveFormat |  |  | 否 | 0 | 仅用于 record | 倒计时几秒开始录音，0：立即开始，-1：不自动开始； |
| filePath | 文件保存路径 |  | 否 |  |  | 可选。可以为：1）留空(自动保存到TEMP目录中)。2）完整的文件路径。3）保存目录(自动生成文件名)。 |
| autoStartSeconds | 自动开始录音 | Enum | 否 |  | 仅用于 record, short_voice_input |  |
| helpText | 提示文字 | Text | 否 |  | 仅用于 short_voice_input |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| outputFilePath | 文件保存路径 | Text | 仅用于 record, record_internal | 音频文件的完整路径。 |
| speechContent | 语音文字内容 | Text | 仅用于 short_voice_input | 获得的语音输入内容 |
| error | 错误 | Text | 仅用于 short_voice_input | 失败原因提示消息 |

## 要点
- 控制参数: `vendorAccount`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
