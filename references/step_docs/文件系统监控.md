# 文件系统监控

- 模块键: `sys:fileSystemWatch`
- 步骤类型: `Action`
- 说明: 监控文件创建/变更/删除等事件。
- 帮助: https://getquicker.net/KC/Help/Doc/filesystemwatch

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:fileSystemWatch",
  "InputParams": {
    "operation": {
      "VarKey": "",
      "Value": "wait"
    },
    "path": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "includeSubdirectories": {
      "VarKey": "",
      "Value": "true"
    },
    "filter": {
      "VarKey": "",
      "Value": "*.*"
    },
    "notifyFilter": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "createdCallback": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "changedCallback": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "renamedCallback": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "fullPath": "out_fullPath",
    "changedType": "out_changedType",
    "oldFullPath": "out_oldFullPath"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| operation | 操作类型 | Enum | 否 | wait | wait=等待事件发生 / callback=持续监控（事件发生后调用子程序） | 时间数据来源 |
| path | 文件夹路径 | Text | 否 |  |  | 要监控的文件夹路径 |
| includeSubdirectories | 包含子文件夹 | Boolean | 否 | true |  |  |
| filter | 文件筛选 | Text | 否 | *.* |  | 筛选要监控的文件。可指定文件名（如foo.txt），或使用通配符（如*.txt） |
| notifyFilter | 通知筛选 | Text | 否 |  |  | 可选，可选值请参考文档。留空表示默认设置(LastWrite,FileName,DirectoryName)。 |
|  |  |  | 否 | 0 | 仅用于 wait | 最长等待时间。0表示不限时间。 |
| createdCallback | [创建] 处理子程序 | Text | 否 |  | 仅用于 callback | 文件或文件创建时调用的子程序 |
| changedCallback | [变更] 处理子程序 | Text | 否 |  | 仅用于 callback | 文件或文件夹变更时调用的子程序 |
| renamedCallback | [重命名] 处理子程序 | Text | 否 |  | 仅用于 callback | 文件或文件重命名时调用的子程序 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| fullPath | 变更的路径 | Text | 仅用于 wait | 发生变更的文件(夹)路径，或重命名后的新路径 |
| changedType | 变更类型 | Text | 仅用于 wait | 变更类型 |
| oldFullPath | 旧路径 | Text | 仅用于 wait | 重命名时的原始路径 |

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
