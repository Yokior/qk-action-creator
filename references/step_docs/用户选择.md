# 用户选择

- 模块键: `sys:select`
- 步骤类型: `Action`
- 说明: 请用户选择一个选项。
- 帮助: https://getquicker.net/KC/Help/Doc/userselect

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | single | single=单选 / multi=多选 |  |
| prompt | 窗口标题 | Text | 是 | 请选择 |  |  |
| note | 提示信息 | Text | 否 |  |  |  |
| items | 选项 | Text | 是 |  |  | 每行一个选项，格式为 “文本” 或 “显示文本|值”。如需显示图标，格式请参考文档。 |
| defaultValue | 默认值 | Text | 否 |  | 仅用于 single | 预先选择的项 |
| defaultValueMulti | 默认值 | Text | 否 |  | 仅用于 multi | 多选时默认选项，每行一个 |
| showFilter | 启用筛选 | Enum | 否 | auto | 0=不启用 / 1=启用 / auto=自动(选项超过10个时启用) | 是否显示筛选框。仅在且使用焦点时有效。 |
| filterContent | 筛选内容 | Text | 否 |  |  | 预先显示的筛选内容 |
| imeState | 输入法状态 | Enum | 否 | NO_CONTROL | NO_CONTROL=不控制 / ON=开启 / OFF=关闭 | 筛选框输入法状态 |
| operations | 右键/全局菜单 | Text | 否 |  |  | 每行定义一个操作，具体格式请参考文档。 |
| fontsize | 字体大小 | Number | 是 | 12 |  |  |
| fontfamily | 字体名称 | Text | 否 |  |  | 可选。设置字体名称。如有多个字体，使用逗号分隔。 |
| iconsize | 图标大小 | Number | 是 | 16 |  |  |
| autoCloseSeconds | 自动关闭 | Number | 否 | 0 |  | 几秒后自动关闭选择窗口。0表示不自动关闭。 |
| enableQuickConfirm | 启用快速确认（点击选项后立即确认选择并关闭窗口） | Enum | 否 | ShowWindowLocation.WithMouse1 |  |  |
| maxWinSize | 最大尺寸/位置坐标 | Text | 否 |  |  | 可选。设置选择窗口的最大尺寸，格式为：宽度,高度。支持像素数值或屏幕宽高百分比，详情请参考模块文档。\n“窗口位置” 类型为 “自定义位置” 时用于指定显示位置，格式为：left,top,right,bottom |
| keepLastPos | 使用上次位置 | Enum | 否 | 1 | 0=不保持 / 3=保持本次运行的上次位置(左上角) / 1=保持本次运行的上次位置+宽度 / 5=保持本次运行的上次位置+尺寸 / 7=保持本次运行的上次窗口尺寸 / 4=总是保持上次位置(左上角) / 2=总是保持上次位置+宽度 / 6=总是保持上次位置+尺寸 / 8=总是保持上次窗口尺寸 | 重复显示选择窗口时，保持上次的显示位置。 |
| noKeyboard | 不使用焦点 | Boolean | 否 | false |  | 不抢占其他应用的焦点。此时无法使用键盘选择选项，只能用鼠标操作。 |
| closeOnDeactivated | 失去焦点后关闭窗口（仅在使用焦点时有效） | Boolean | 否 | false |  |  |
| restoreForeground | 恢复活动窗口到弹出前 | Boolean | 否 | true |  | 将前台窗口还原为弹窗前的活动窗口。否则将会还原到最后一个活动窗口上。 |
| allowOkWhenEmpty | 允许不选择任何选项时点击确定 | Boolean | 否 | false |  |  |
| winLocation | 窗口位置 | Boolean | 否 | true | 仅用于 single |  |
| topMost | 置顶显示 | Boolean | 否 | true |  |  |
| windowKey | 窗口标识 | Text | 否 |  |  | 再次运行动作时，可根据标识自动关闭前一个窗口并在该位置显示新窗口。 |
| help | 帮助按钮内容 | Text | 否 |  |  | 点击弹出显示帮助内容，MarkDown格式 |
| stopIfCancel | 取消后停止 | Boolean | 否 | true |  | 取消选择后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否确认 | Boolean |  | 是否成功选择了选项/点击了保存按钮 |
| selectedIndex | 索引号 | Integer | 仅用于 single | 选择的项在列表里的序号数字，从0开始。 |
| selectedIndexList | 索引号列表 | List | 仅用于 multi | 所有选择的项的序号列表 |
| multiSelected | 选择的项值列表 | List | 仅用于 multi | 所有选择的项的值的列表 |
| extraOperation | 选择的菜单 | Text |  | 选择的右键菜单或全局菜单项的值 |
| selectedFullItems | 选择的完整选项 | Any |  | 选择选项的完整定义内容（不仅仅返回选项值） |
| selectedItemTitle | 选择的选项标题 | Text | 仅用于 single | 所选中选项的标题 |
| filterContent | 筛选内容 | Text |  | 最后使用的筛选词 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
