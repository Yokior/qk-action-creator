# 文本窗口

- 模块键: `sys:showText`
- 步骤类型: `Action`
- 说明: 在独立的窗口中显示文本。
- 帮助: https://getquicker.net/KC/Help/Doc/showText

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 操作类型 |  | 否 |  | NO_WAIT=显示窗口，不等待关闭（立即开始执行后续的步骤） / WAIT=显示窗口，等待关闭 / CLOSE_WINDOW=关闭窗口 / GET_WIN_INFO=获取窗口信息 / APPEND_TEXT=追加内容 / ACTIVATE_WINDOW=显示和激活窗口 / WAIT_CLOSE=等待窗口关闭 / GET_ALL_WINDOWS=获取所有文本窗口 / GET_ACTION_WINDOWS=获取当前动作创建的所有文本窗口 |  |
| text | 文本内容 | Text | 是 |  | 仅用于 WAIT, NO_WAIT, APPEND_TEXT | 要显示的文本内容 |
| title | 窗口标题 | Text | 是 | 文本窗口 | 仅用于 WAIT, NO_WAIT | 窗口标题文字 |
| winLocation |  |  | 否 |  |  |  |
| operations | 工具栏操作 | Text | 否 |  | 仅用于 WAIT, NO_WAIT；不用于 GET_ALL_WINDOWS, GET_ACTION_WINDOWS | 是否等待窗口关闭后继续 |
| winSize | 窗口尺寸/位置 | Text | 否 |  | 仅用于 WAIT, NO_WAIT | 设置选择窗口的尺寸，格式为：宽度,高度。支持逻辑像素数值或屏幕宽高百分比，详情请参考模块文档。\n“窗口位置” 类型为 “自定义位置” 时用于指定显示位置，格式为：left,top,right,bottom |
| fontsize | 字体大小 | Number | 是 | 14 | 仅用于 WAIT, NO_WAIT | 默认的字体大小 |
| fontfamily | 字体名称 | Text | 否 |  | 仅用于 WAIT, NO_WAIT | 可选。设置字体名称。如有多个字体，使用逗号分隔。 |
| bgColor | 背景颜色 | Text | 否 |  | 仅用于 WAIT, NO_WAIT | 可选。格式为#RRGGBB |
| textColor | 文字颜色 | Text | 否 |  | 仅用于 WAIT, NO_WAIT | 可选。格式为#RRGGBB |
| highlight | 语法高亮 | Enum | 否 |  | 仅用于 WAIT, NO_WAIT |  |
| autoSaveToState | 自动保存到状态 | Text | 否 |  | 仅用于 WAIT, NO_WAIT | 指定状态Key。文本内容将自动保存到状态中。 |
| topMost | 置顶显示 | Boolean | 否 | false | 仅用于 WAIT, NO_WAIT |  |
| enableEscClose | Esc 键关闭窗口 | Boolean | 否 | true | 仅用于 WAIT, NO_WAIT |  |
| closeWhenLostFocus | 失去焦点自动关闭 | Boolean | 否 | false | 仅用于 WAIT, NO_WAIT |  |
| showLineNum | 显示行号 | Boolean | 否 | true | 仅用于 WAIT, NO_WAIT |  |
| autoWrap | 自动换行显示 | Boolean | 否 | true | 仅用于 WAIT, NO_WAIT |  |
| showBuildInToolbar | 显示内置工具栏 | Boolean | 否 | true | 仅用于 WAIT, NO_WAIT |  |
| copyWholeLine | 未选择内容时，复制或剪切整行 | Boolean | 否 | false | 仅用于 WAIT, NO_WAIT |  |
| caretPosition | 光标位置 | Integer | 是 | 0 | 仅用于 WAIT, NO_WAIT | 0表示最前面，-1表示最后面，其它数字表示某个具体字符位置。 |
| advancedSettings | 高级设置 | Text | 否 |  |  | 请参考模块文档。 |
| updateIfExists | 如果窗口存在，则直接更新窗口内容（而不是关闭后打开新窗口） | Boolean | 否 | false | 仅用于 NO_WAIT |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| selectedOperation | 选择的项 | Text | 仅用于 WAIT | 选择的后续操作项 |
| resultText | 结果文本 | Text | 仅用于 WAIT, CLOSE_WINDOW, GET_WIN_INFO | 文本框内的所有文本 |
| selectedText | 选中的文本 | Text | 仅用于 WAIT, CLOSE_WINDOW, GET_WIN_INFO | 文本框内选中的文本 |
| windowHandle | 窗口句柄 | Integer | 仅用于 NO_WAIT, GET_WIN_INFO |  |
| windowPosition | 窗口位置 | Text | 仅用于 WAIT, CLOSE_WINDOW, GET_WIN_INFO | 窗口的最终显示位置 |
| allWindows | 所有窗口 | Dict | 仅用于 GET_ALL_WINDOWS, GET_ACTION_WINDOWS | 词典类型，key为窗口的句柄，value为窗口的标识。获取全部窗口时，为了安全，仅限自己开发的动作使用。 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
