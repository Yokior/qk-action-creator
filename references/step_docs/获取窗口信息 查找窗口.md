# 获取窗口信息/查找窗口

- 模块键: `sys:getWindowTitle`
- 步骤类型: `Action`
- 说明: 获取指定窗口的标题等信息。
- 帮助: https://getquicker.net/KC/Help/Doc/getwindowtitle

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:getWindowTitle",
  "InputParams": {
    "which": {
      "VarKey": "",
      "Value": "foreground"
    },
    "className": {
      "VarKey": "",
      "Value": 0
    },
    "requireTitle": {
      "VarKey": "",
      "Value": "true"
    },
    "windowName": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "onlyVisible": {
      "VarKey": "",
      "Value": "default"
    },
    "hWnd": {
      "VarKey": "",
      "Value": false
    },
    "useRegex": {
      "VarKey": "",
      "Value": "false"
    },
    "winRectIncludeInvisibleBorder": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "output": "out_output",
    "className": "out_className",
    "handle": "out_handle",
    "pid": "out_pid",
    "procName": "out_procName",
    "path": "out_path",
    "parent": "out_parent",
    "root": "out_root",
    "rootOwner": "out_rootOwner",
    "rect": "out_rect",
    "rectNoSize": "out_rectNoSize",
    "rectDict": "out_rectDict",
    "isTopmost": "out_isTopmost",
    "isVisible": "out_isVisible",
    "showState": "out_showState",
    "alpha": "out_alpha",
    "allChildWindows": "out_allChildWindows",
    "topLevelWindows": "out_topLevelWindows"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| which | 目标窗口 | Enum | 是 | foreground | foreground=前台窗口 / selectWindow=选择一个窗口 / pointing=弹出面板前鼠标位置的窗口（可能为子窗口） / pointing_root=弹出面板前鼠标位置窗口的根窗口 / pointing_now=当前鼠标位置的窗口（可能为子窗口） / pointing_now_root=当前鼠标位置窗口的根窗口 / fromHwnd=句柄指定的窗口 / findWindow=查找顶层窗口 (单个窗口) / top_windows=所有顶层窗口 / findChildWindow=查找子窗口/控件 (单个窗口) / child_windows=查找子窗口 (多个窗口) | 判断哪个窗口的信息 |
| className | 窗口类名 | Integer | 否 |  | 仅用于 fromHwnd, findChildWindow, child_windows | 未指定时使用前台窗口句柄 |
| requireTitle | 仅名称(标题)不为空的窗口 |  | 否 | true |  |  |
| windowName | 窗口名称 | Text | 否 |  | 仅用于 findWindow, top_windows, findChildWindow, child_windows | 要查找窗口的标题，为空时不检查此项。 |
| onlyVisible | 仅可见窗口 | Text | 否 | default | 仅用于 findWindow, top_windows |  |
| hWnd | 窗口句柄hWnd | Boolean | 否 |  | 仅用于 top_windows, findWindow |  |
| useRegex | 使用正则匹配窗口类名和标题 | Boolean | 否 | false | 仅用于 findWindow, top_windows, child_windows |  |
| winRectIncludeInvisibleBorder | 窗口位置包含不可见边框（阴影区域） | Boolean | 否 | false | 不用于 top_windows, findChildWindow, child_windows |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| output | 窗口标题 | Text | 不用于 top_windows, findChildWindow, child_windows | 窗口的标题文字 |
| className | 类名 | Text | 不用于 top_windows, findChildWindow, child_windows | 窗口的 Class Name |
| handle | 句柄 | Integer | 不用于 top_windows, child_windows | 窗口的句柄 |
| pid | 进程ID | Integer | 不用于 top_windows, findChildWindow, child_windows | 窗口所属进程的ID |
| procName | 进程名 | Text | 不用于 top_windows, findChildWindow, child_windows | 进程名称 |
| path | 程序路径 | Text | 不用于 top_windows, findChildWindow, child_windows | 获得的进程路径 |
| parent | 父窗口句柄 | Integer | 不用于 top_windows, findChildWindow, child_windows |  |
| root | 根窗口句柄 | Integer | 不用于 top_windows, findChildWindow, child_windows |  |
| rootOwner | 根所有者窗口句柄 | Integer | 不用于 top_windows, findChildWindow, child_windows |  |
| rect | 窗口位置 | Text | 不用于 top_windows, findChildWindow, child_windows | 文本值，格式为:Left,Top,Right,Bottom,Width,Height。 |
| rectNoSize | 窗口位置(不含尺寸) | Text | 不用于 top_windows, child_windows | 文本值，格式为:Left,Top,Right,Bottom。如:0,0,100,100 |
| rectDict | 窗口位置(词典值) | Dict | 不用于 top_windows, child_windows | 词典值，属性为:Left,Top,Right,Bottom,Width,Height |
| isTopmost | 是否置顶 | Boolean | 不用于 top_windows, findChildWindow, child_windows |  |
| isVisible | 是否可见 | Boolean | 不用于 top_windows, findChildWindow, child_windows |  |
| showState | 显示状态 | Integer | 不用于 top_windows, findChildWindow, child_windows | 1:普通，2:最小化，3:最大化。 |
| alpha | 不透明度 | Integer | 不用于 top_windows, findChildWindow, child_windows | 窗口的透明度，范围为0-255。0表示全透明 |
| allChildWindows | 所有子窗口 | Dict | 不用于 top_windows, findChildWindow | 词典值，Key为窗口句柄，Value为窗口标题 |
| topLevelWindows | 所有顶层窗口 | Dict | 仅用于 top_windows | 词典值，Key为窗口句柄，Value为窗口标题 |

## 要点
- 控制参数: `which`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
