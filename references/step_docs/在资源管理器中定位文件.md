# 在资源管理器中定位文件

- 模块键: `sys:SelectFileInExplorer`
- 步骤类型: `Action`
- 说明: 在资源管理器中选中文件
- 帮助: https://getquicker.net/KC/Help/Doc/selectfileinexplorer

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:SelectFileInExplorer",
  "InputParams": {
    "path": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| path | 路径 | Text | 是 |  |  | 要定位的文件完整路径。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
