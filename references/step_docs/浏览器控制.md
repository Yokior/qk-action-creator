# 浏览器控制

- 模块键: `sys:chromecontrol`
- 步骤类型: `Action`
- 说明: 与Chrome/Edge/Firefox等浏览器通信，控制网页或浏览器。
- 帮助: https://getquicker.net/KC/Help/Doc/chromecontrol

## 要点
- 控制参数: `operation`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `RunScript` 的 `script` 若为多行脚本，JSON 里使用 `\r\n` 表示换行，不要写成字面量 `\\r\\n`。
- `RunScript` 也可以直接写单行脚本；当你只需要做一次简单 DOM 操作时，单行更稳妥。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
