# 管理和排序列表

- 模块键: `sys:manageList`
- 步骤类型: `Action`
- 说明: 对列表内容进行手工排序、添加、删除等操作
- 帮助: https://getquicker.net/KC/Help/Doc/managelist

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:manageList",
  "InputParams": {
    "list": {
      "VarKey": "",
      "Value": "item1\\nitem2"
    },
    "winTitle": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "note": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "parseData": {
      "VarKey": "",
      "Value": "false"
    },
    "seperator": {
      "VarKey": "",
      "Value": "|"
    },
    "windowSize": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "allowAdd": {
      "VarKey": "",
      "Value": "true"
    },
    "allowEdit": {
      "VarKey": "",
      "Value": "true"
    },
    "allowDelete": {
      "VarKey": "",
      "Value": "true"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "false"
    },
    "help": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "titleDelegate": {
      "VarKey": "",
      "Value": "示例文本"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| list | 列表 | List | 否 |  |  | 要操作的列表变量。直接选择对应变量，不要使用表达式。 |
| winTitle | 窗口标题 | Text | 否 |  |  |  |
| note | 提示信息 | Text | 否 |  |  |  |
| parseData | 解析菜单数据 | Boolean | 否 | false |  | 解析 “[图标]标题(tooltip)|值” 格式的数据并显示图标。 |
| seperator | 分隔符 | Text | 否 | | |  | 解析菜单数据时，显示内容与值之间的分隔符，默认为竖线'|' |
| windowSize | 窗口宽度 | Text | 否 |  |  | 可选，在需要自定义窗口宽度的情况下使用。最小值为200。 |
| allowAdd | 允许添加项 | Boolean | 否 | true |  |  |
| allowEdit | 允许编辑项 | Boolean | 否 | true |  |  |
| allowDelete | 允许删除项 | Boolean | 否 | true |  |  |
| stopIfFail | 取消后停止动作 | Boolean | 否 | false |  |  |
| help | 帮助按钮内容 | Text | 否 |  |  | 点击弹出显示帮助内容，MarkDown格式 |
| titleDelegate | 显示内容提取表达式 | Text | 否 |  |  | 可选，在不解析菜单数据时自定义每一项的显示内容。使用方式请参考模块文档。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否确认 | Boolean |  | 是否点击了确认按钮 |

## 要点
- 部分参数偏向变量模式。此类参数实际写入时应优先填写 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
