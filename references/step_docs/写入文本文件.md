# 写入文本文件

- 模块键: `sys:WriteTextFile`
- 步骤类型: `Action`
- 说明: 将内容写入文本文件
- 帮助: https://getquicker.net/KC/Help/Doc/writetextfile

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:WriteTextFile",
  "InputParams": {
    "content": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "filePath": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "encoding": {
      "VarKey": "",
      "Value": "utf-8"
    },
    "addUtf8Bom": {
      "VarKey": "",
      "Value": "false"
    },
    "appendMode": {
      "VarKey": "",
      "Value": "false"
    },
    "addNewLine": {
      "VarKey": "",
      "Value": "false"
    },
    "newLineChars": {
      "VarKey": "",
      "Value": ""
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| content | 内容 | Text | 是 |  |  | 要写入文件的内容 |
| filePath | 文件路径 | Text | 是 |  |  | 要写入的完整文件路径（包含文件名） |
| encoding | 文件编码 | Enum | 是 | utf-8 |  | 写入文件的编码格式 |
| addUtf8Bom | 添加UTF-BOM | Boolean | 否 | false |  | UTF8编码文件是否写入BOM标记 |
| appendMode | 添加到文件末尾 | Boolean | 否 | false |  | 如果文件已存在，则添加到文件的末尾 |
| addNewLine | 添加空行 | Boolean | 否 | false |  | 在文件末尾添加空行 |
| newLineChars | 统一换行字符 | Enum | 是 |  | =默认（不处理） |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
