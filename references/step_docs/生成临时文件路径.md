# 生成临时文件路径

- 模块键: `sys:GenTempFilePath`
- 步骤类型: `Action`
- 说明: 根据指定的扩展名生成一个随机的临时文件名（完整路径），供后续步骤写入文件使用。
- 帮助: https://getquicker.net/KC/Help/Doc/gentempfilepath

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:GenTempFilePath",
  "InputParams": {
    "ext": {
      "VarKey": "",
      "Value": ".txt"
    }
  },
  "OutputParams": {
    "filePath": "out_filePath"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| ext | 扩展名 | Text | 是 | .txt |  | 生成临时文件的扩展名 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| filePath | 文件路径 | Text |  | 生成的临时文件路径 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
