# 计算时间

- 模块键: `sys:computeTime`
- 步骤类型: `Action`
- 说明: 时间相关的计算操作
- 帮助: https://getquicker.net/KC/Help/Doc/computetime

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:computeTime",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "getdate"
    },
    "time1": {
      "VarKey": "",
      "Value": "2026-01-01 00:00:00"
    },
    "addYears": {
      "VarKey": "",
      "Value": "0"
    },
    "addMonths": {
      "VarKey": "",
      "Value": "0"
    },
    "addDays": {
      "VarKey": "",
      "Value": "0"
    },
    "addHours": {
      "VarKey": "",
      "Value": "0"
    },
    "addMinutes": {
      "VarKey": "",
      "Value": "0"
    },
    "addSeconds": {
      "VarKey": "",
      "Value": "0"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "resultTime": "out_resultTime",
    "totalDays": "out_totalDays",
    "totalHours": "out_totalHours",
    "totalMinutes": "out_totalMinutes",
    "totalSeconds": "out_totalSeconds"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | getdate | getdate=取日期值（去除当天的时间部分） / timespan=计算时间差（日期时间2 减 日期时间） / endtime=计算结束时间 / localToUtc=本地时间转换为UTC时间 / utcToLocal=UTC时间转换为本地时间 | 比较方式 |
| time1 | 日期时间 | DateTime | 是 |  |  | 要计算的时间值 |
|  |  | DateTime | 是 |  | 仅用于 timespan | 要计算的第二个时间值 |
| addYears | 添加年数 | Number | 否 | 0 | 仅用于 endtime | 添加指定的年数（整数） |
| addMonths | 添加月数 | Number | 否 | 0 | 仅用于 endtime | 添加指定的月数（整数）结果不跨月，如1月31日增加1个月等于2月28日。 |
| addDays | 添加天数 | Number | 否 | 0 | 仅用于 endtime | 添加指定的天数（可以为小数） |
| addHours | 添加小时数 | Number | 否 | 0 | 仅用于 endtime | 添加指定的小时数（可以为小数） |
| addMinutes | 添加分钟数 |  | 否 | 0 | 仅用于 endtime |  |
| addSeconds | 添加秒数 | Number | 否 | 0 | 仅用于 endtime | 添加指定的秒数（可以为小数） |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| resultTime | 结果时间 | DateTime | 仅用于 endtime, getdate, utcToLocal, localToUtc | 计算的结果时间 |
| totalDays | 总天数 | Number | 仅用于 timespan | 间隔的总天数值 |
| totalHours | 总小时数 | Number | 仅用于 timespan | 间隔的总小时数 |
| totalMinutes | 总分钟数 | Number | 仅用于 timespan | 间隔的总分钟数值 |
| totalSeconds | 总秒数 | Number | 仅用于 timespan | 间隔的总秒数数值 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
