# 激活进程主窗口

- 模块键: `sys:activateProcessMainWindow`
- 步骤类型: `Action`
- 说明: 找到指定进程的主窗口并使其显示在前台。
- 帮助: https://getquicker.net/KC/Help/Doc/activateprocessmainwindow

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:activateProcessMainWindow",
  "InputParams": {
    "process": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "className": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "windowTitle": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "hotkey": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "path": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "pid": "out_pid",
    "mainWinHandle": "out_mainWinHandle",
    "mainWinTitle": "out_mainWinTitle"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| process | 进程名称/pid | Text | 是 |  |  | 请输入要验证的进程名称或pid。进程名通常是exe的文件名去掉后缀，比如记事本程序的进程名称为notepad。 |
| className | 窗口类名 | Text | 否 |  |  | 选填。未能获取主窗口时（如窗口隐藏），可以尝试根据类名查找窗口，支持正则。 |
| windowTitle | 窗口标题 | Text | 否 |  |  | 选填。未能获取主窗口时，根据窗口标题查找，支持正则。 |
| hotkey | 热键 | Text | 否 |  |  | 选填。软件最小化到托盘时，使用指定的全局热键激活窗口。 |
| path | 程序路径 | Text | 是 |  |  | 选填。如果进程不存在，可以根据此路径启动程序。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 是否成功激活了进程主窗口 |
| pid | PID | Integer |  | 进程ID |
| mainWinHandle | 主窗口句柄 | Integer |  | 进程的主窗口句柄 |
| mainWinTitle | 主窗口标题 | Text |  |  |

## 要点
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
