# 自定义窗口

- 模块键: `sys:customwindow`
- 步骤类型: `Action`
- 说明: 创建和显示自定义窗口
- 帮助: https://getquicker.net/KC/Help/Doc/customwindow

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:customwindow",
  "InputParams": {
    "winLocation": {
      "VarKey": "",
      "Value": ""
    },
    "windowMarkup": {
      "VarKey": "",
      "Value": "<Window xmlns=\\\"http://schemas.microsoft.com/winfx/2006/xaml/presentation\\\"\\r\\n xmlns:d=\\\"http://schemas.microsoft.com/expression/blend/2008\\\"\\r\\n xmlns:x=\\\"http://schemas.microsoft.com/winfx/2006/xaml\\\"\\r\\n xmlns:hc=\\\"https://handyorg.github.io/handycontrol\\\"\\r\\n xmlns:mc=\\\"http://schemas.openxmlformats.org/markup-compatibility/2006\\\"\\r\\n xmlns:qk=\\\"https://getquicker.net\\\"\\r\\n Width=\\\"637\\\"\\r\\n Height=\\\"556\\\"\\r\\n Title=\\\"Test Window\\\"\\r\\n mc:Ignorable=\\\"d\\\">\\r\\n <Grid Margin=\\\"10\\\">\\r\\n <StackPanel>\\r\\n <TextBlock Margin=\\\"10,50,10,50\\\" Text=\\\"Hello World！\\\" FontSize=\\\"20\\\" />\\r\\n \\r\\n <Button Margin=\\\"10\\\" qk:Att.Action=\\\"close:result\\\" Style=\\\"{StaticResource ButtonPrimary}\\\" Width=\\\"50\\\">\\r\\n 关闭\\r\\n </Button>\\r\\n </StackPanel>\\r\\n </Grid>\\r\\n</Window>"
    },
    "dataMapping": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "cscode": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "events": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "windowId": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "autoCloseTime": {
      "VarKey": "",
      "Value": "0"
    },
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| winLocation |  |  | 否 |  |  |  |
| windowMarkup | 窗口XAML代码 | Text | 是 | <Window xmlns=\"http://schemas.microsoft.com/winfx/2006/xaml/presentation\"\r\n xmlns:d=\"http://schemas.microsoft.com/expression/blend/2008\"\r\n xmlns:x=\"http://schemas.microsoft.com/winfx/2006/xaml\"\r\n xmlns:hc=\"https://handyorg.github.io/handycontrol\"\r\n xmlns:mc=\"http://schemas.openxmlformats.org/markup-compatibility/2006\"\r\n xmlns:qk=\"https://getquicker.net\"\r\n Width=\"637\"\r\n Height=\"556\"\r\n Title=\"Test Window\"\r\n mc:Ignorable=\"d\">\r\n <Grid Margin=\"10\">\r\n <StackPanel>\r\n <TextBlock Margin=\"10,50,10,50\" Text=\"Hello World！\" FontSize=\"20\" />\r\n \r\n <Button Margin=\"10\" qk:Att.Action=\"close:result\" Style=\"{StaticResource ButtonPrimary}\" Width=\"50\">\r\n 关闭\r\n </Button>\r\n </StackPanel>\r\n </Grid>\r\n</Window> | 仅用于 Show, ShowAndWaitClose | 窗口定义XAML代码 |
| dataMapping | 数据映射 | Text | 是 |  | 仅用于 Show, ShowAndWaitClose | 将变量与窗口上下文数据进行映射。每行一个，格式为:“窗口数据项名称:{动作变量名}” 或 “窗口数据项:=表达式” |
| cscode | 辅助C#代码 | Text | 否 |  | 仅用于 Show, ShowAndWaitClose | 辅助处理窗口事件的代码，详见文档。 |
| events | 事件 | Text | 是 |  | 仅用于 Show, ShowAndWaitClose | 详细说明请参考模块文档 |
| windowId | 窗口标识 | Text | 是 |  |  | 如需单独的步骤关闭窗口，需使用标识查找窗口。 |
| autoCloseTime | 自动关闭时间(S) | Number | 是 | 0 | 仅用于 Show, ShowAndWaitClose | 自动关闭窗口的时间（秒数）。需大于0.5秒。 |
| activateMode | 激活模式 | Enum | 否 | AutoActivate | NotActivatable=不支持激活（不占用焦点，仅能使用鼠标操作） / NotActivatableMouseThrough=不支持激活，鼠标穿透 / NotActivated=支持激活，打开时不抢占焦点 / AutoActivate=支持激活，打开时抢占焦点；仅用于 Show, ShowAndWaitClose |  |
| winSize | 窗口尺寸/位置 | Text | 否 |  | 仅用于 Show, ShowAndWaitClose | 设置选择窗口的最大尺寸，格式为：宽度,高度。支持像素数值或屏幕宽高百分比，详情请参考模块文档。\n“窗口位置” 类型为 “自定义位置” 时用于指定显示位置，格式为：left,top,right,bottom |
| closeWhenDeactivate | 失去焦点后关闭窗口 | Boolean | 否 | false | 仅用于 Show, ShowAndWaitClose | 仅在窗口支持激活（获取焦点）的情况下有效。 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| result | 窗口结果 | Text | 仅用于 ShowAndWaitClose, Close | 通过close:result返回的结果 |
| windowList | 窗口对象列表 | Object | 仅用于 GetWindows | IList<Window>对象 |
| windowHandle | 窗口句柄 | Integer | 仅用于 Show |  |
| windowLocation | 关闭时窗口位置 | Text | 仅用于 ShowAndWaitClose |  |

## 要点
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
