# 用户输入

- 模块键: `sys:userInput`
- 步骤类型: `Action`
- 说明: 请用户输入内容。
- 帮助: https://getquicker.net/KC/Help/Doc/userInput

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | text | text=单行文本 / multiline=多行文本 / number=数字 / date_time=日期时间 | 输入内容的类型 |
| prompt | 提示文字 | Text | 是 | 请输入内容 |  | 提示用户输入什么内容。显示在输入框上方。 |
| defaultValue | 默认值 | Text | 否 |  |  | 默认填写到输入框中的内容 |
| texttools | 文本选择工具 | Text | 否 |  | 仅用于 text, multiline | 鼠标悬浮在文本框上时显示的小工具 |
| extraSettings | 扩展设置 | Text | 否 |  | 仅用于 text, multiline | 可用于自定义文本选择工具，详情请参考文档。 |
| pattern | 验证表达式 | Text | 否 |  | 仅用于 text, multiline, number | 正则验证表达式 |
| isRequired | 必填 | Boolean | 否 | false |  | 是否必须填写内容 |
| fontfamily | 字体名称 | Text | 否 |  | 仅用于 text, multiline, number | 可选。设置字体名称。如有2个字体，使用逗号分隔。 |
| fontsize | 字体大小 | Number | 是 | 14 | 仅用于 text, multiline, number |  |
| winLocation | 窗口位置 | Enum | 否 | ShowWindowLocation.CenterScreen |  | 在哪里显示选择窗口 |
| imeState | 输入法状态 | Enum | 否 | NO_CONTROL | NO_CONTROL=不控制 / ON=开启 / OFF=关闭；仅用于 text, multiline |  |
| submitWithReturn | 回车提交结果（Shift+回车换行） | Boolean | 否 | false | 仅用于 multiline |  |
| restoreFocus | 恢复活动窗口 | Boolean | 否 | true |  | 用户输入后，是否将焦点还原到之前的活动窗口 |
| closeOnDeactivated | 失去焦点后关闭窗口 | Boolean | 否 | false |  |  |
| help | 帮助按钮内容 | Text | 否 |  |  | 点击弹出显示帮助内容，MarkDown格式 |
| topMost | 置顶显示 | Boolean | 否 | false |  |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 用户取消后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| textValue | 文本值 | Text |  | 文本类型的输入值 |
| numberValue | 数字值 | Number | 仅用于 number | 数字类型的输入值 |
| datetimeValue | 日期时间值 | DateTime | 仅用于 date_time |  |
| isEmpty | 是否为空 | Boolean |  | 用户是否没有输入内容 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
