# 获取选中的文本

- 模块键: `sys:getSelectedText`
- 步骤类型: `Action`
- 说明: 获取选中的文字
- 帮助: https://getquicker.net/KC/Help/Doc/get_selected_text

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:getSelectedText",
  "InputParams": {
    "format": {
      "VarKey": "",
      "Value": "UnicodeText"
    },
    "waitMs": {
      "VarKey": "",
      "Value": "250"
    },
    "repeat": {
      "VarKey": "",
      "Value": "0"
    },
    "trim": {
      "VarKey": "",
      "Value": "false"
    },
    "tryNoClipboard": {
      "VarKey": "",
      "Value": "false"
    },
    "useActionParam": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "output": "out_output",
    "cleanHtml": "out_cleanHtml",
    "outputEncoded": "out_outputEncoded",
    "url": "out_url"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| format | 文本数据格式 | Enum | 否 | UnicodeText | UnicodeText=纯文本（默认） / CommaSeparatedValue=逗号分隔的值（csv） | 需要读取的剪贴板文本内容格式。通常请使用Unicode纯文本格式。 |
| waitMs | 等待剪贴板时间 | Integer | 否 | 250 |  | 模拟复制键后，等待剪贴板变化的最长时间毫秒数。 |
| repeat | 重试次数 | Integer | 否 | 0 |  | 【已过时，仅为兼容性保留】失败后重试的次数。 |
| trim | 去除前后的空白 | Boolean | 否 | false |  | 去除内容前后的空白（包括空行）。 |
| tryNoClipboard | 尝试不通过剪贴板的方式获取 | Boolean | 否 | false |  | 通过UIAutomation方式获取（某些情况可能出现无法完整获取文字、失去换行信息等问题） |
| useActionParam | 如果为动作传递了参数，使用参数值作为获取的结果 | Boolean | 否 | false |  | 没有传递参数时仍尝试获取选中的文本。 |
| stopIfFail | 失败后中止动作 | Boolean | 否 | true |  | 获取选中的文本失败后，是否停止后续动作的执行。 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 是否成功获取了文本 |
| output | 内容 | Text |  | 将获得的文本写入到变量 |
| cleanHtml | 去除封装的HTML | Text | 仅用于 Html | 剪贴板HTML的主要内容<!--StartFragment-->和<!--EndFragment-->之间的部分 |
| outputEncoded | URL编码的内容 | Text |  | 对选中的内容进行URL编码处理后的结果，通常用于拼接网址。 |
| url | 来源网址 | Text |  | 从网页中复制内容时，可能会携带网址信息。 |

## 要点
- 控制参数: `format`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
