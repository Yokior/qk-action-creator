# 运行脚本

- 模块键: `sys:runScript`
- 步骤类型: `Action`
- 说明: 运行脚本。
- 帮助: https://getquicker.net/KC/Help/Doc/runScript

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:runScript",
  "InputParams": {
    "script": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "type": {
      "VarKey": "",
      "Value": "CMD_K"
    },
    "ext": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "encoding": {
      "VarKey": "",
      "Value": "default"
    },
    "runner": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "argTemplate": {
      "VarKey": "",
      "Value": "%FILE%"
    },
    "outputEncoding": {
      "VarKey": "",
      "Value": "oem"
    },
    "workingDir": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "scriptParams": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "runAsAdmin": {
      "VarKey": "",
      "Value": "false"
    },
    "waitToExit": {
      "VarKey": "",
      "Value": "false"
    }
  },
  "OutputParams": {
    "stdout": "out_stdout",
    "stdoutOnly": "out_stdoutOnly",
    "stderr": "out_stderr"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| script | 脚本内容 | Text | 是 |  |  | 要运行的脚本内容 |
| type | 脚本类型 | Enum | 是 | CMD_K | CMD_K=CMD命令 (完成后保留窗口) / CMD_C=CMD命令 (完成后关闭窗口) / CMD_H=CMD命令 (隐藏命令行窗口) / BAT=BAT批处理脚本(.bat) / CMD_F=CMD批处理脚本(.cmd) / PS=PowerShell脚本(.ps1) / AHK=AutoHotKey脚本(.ahk) / CUSTOM=自定义脚本类型 | 要执行的脚本类型 |
| ext | 扩展名 | Text | 是 |  | 仅用于 CUSTOM | 自定义脚本文件的扩展名(如: .ps1 ) |
| encoding | 文件编码 | Enum | 是 | default | UTF8-NOBOM=UTF8 (无BOM) | 写入文件的编码格式 |
| runner | 使用指定软件 | Text | 是 |  | 仅用于 CUSTOM | 使用指定的程序运行脚本。如果双击脚本可以直接运行，则不需要指定。 |
| argTemplate | 命令行参数模板 | Text | 是 | %FILE% | 仅用于 CUSTOM | 使用指定软件时指定命令行参数的格式。%FILE% 代替脚本文件的路径。 |
| outputEncoding | 控制台输出编码 | Enum | 是 | oem | utf8=UTF8 / oem=OEM | 控制台输出编码。如果输出遇到乱码，尝试修改此选项。 |
| workingDir | 工作目录 | Text | 否 |  |  | 不填写（自动为资源管理器的当前目录或桌面目录）或具体的工作目录路径。 |
| scriptParams | 脚本参数 | Text | 否 |  | 不用于 CUSTOM, CMD_C, CMD_H, CMD_K | 为脚本传递的参数。将会被追加到运行脚本的命令行中。 |
| runAsAdmin | 以管理员身份运行 | Boolean | 否 | false |  | 是否以管理员身份运行脚本。隐藏窗口或输出控制台内容时，不支持以管理员身份运行。 |
| waitToExit | 等待进程结束 | Boolean | 否 | false |  | 等待此进程结束后再进行后续操作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| stdout | 控制台输出 | Text |  | 捕获控制台输出(输出stdout，为空时输出stderr)，会自动等待进程结束。输出此内容时，命令行窗口将不显示。 |
| stdoutOnly | 标准输出 | Text |  | 捕获标准输出(stdout)，会自动等待进程结束。输出此内容时，命令行窗口将不显示。 |
| stderr | 错误输出 | Text |  | 捕获错误输出(stderr)，会自动等待进程结束。输出此内容时，命令行窗口将不显示。 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
