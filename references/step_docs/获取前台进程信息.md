# 获取前台进程信息

- 模块键: `sys:getActiveProcessInfo`
- 步骤类型: `Action`
- 说明: 获取当前活动窗口进程的信息。
- 帮助: https://getquicker.net/KC/Help/Doc/getactiveprocessinfo

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:getActiveProcessInfo",
  "InputParams": {
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "path": "out_path",
    "procName": "out_procName",
    "pid": "out_pid",
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| stopIfFail | 失败后中止动作 | Boolean | 否 | true |  | 获取进程信息失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| path | 程序路径 | Text |  | 获得的进程路径 |
| procName | 进程名 | Text |  | 进程名称 |
| pid | PID | Integer |  | 进程ID |
| isSuccess | 是否成功 | Boolean |  | 是否成功获得进程信息 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
