# 选择文件夹

- 模块键: `sys:selectFolder`
- 步骤类型: `Action`
- 说明: 文件夹选择对话框
- 帮助: https://getquicker.net/KC/Help/Doc/selectfolder

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:selectFolder",
  "InputParams": {
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "path": "out_path"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| stopIfFail | 取消后停止 | Boolean | 否 | true |  | 取消后是否停止动作运行 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 是否成功选择了路径。 |
| path | 路径 | Text |  | 选择的文件夹路径。 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
