# 显示菜单

- 模块键: `sys:showmenu`
- 步骤类型: `Action`
- 说明: 显示一个菜单
- 帮助: https://getquicker.net/KC/Help/Doc/showmenu

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:showmenu",
  "InputParams": {
    "menuData": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "fontsize": {
      "VarKey": "",
      "Value": "12"
    },
    "iconsize": {
      "VarKey": "",
      "Value": "16"
    },
    "maxHeight": {
      "VarKey": "",
      "Value": "0"
    },
    "useFocus": {
      "VarKey": "",
      "Value": "false"
    },
    "waitMenuClose": {
      "VarKey": "",
      "Value": "true"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "selectedItemData": "out_selectedItemData",
    "selectedItem": "out_selectedItem"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| menuData | 菜单数据 | Text | 是 |  |  | 可以为Json/菜单文本格式/IList<CommonOperationItem>对象，详情请参考文档 |
| fontsize | 字体大小 | Number | 是 | 12 |  |  |
| iconsize | 图标大小 | Number | 是 | 16 |  | 图标的宽度/高度像素数 |
| maxHeight | 最大高度 | Text | 是 | 0 |  | 可以为百分比（如:50%）或固定数值（如:500）。 |
| useFocus | 占用焦点 | Boolean | 否 | false |  | 是否允许菜单占用焦点（从而可以键盘选择菜单项） |
| waitMenuClose | 等待菜单关闭 | Boolean | 否 | true |  | 是否等待菜单关闭后再运行后续步骤 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| selectedItemData | 选择的菜单项数据 | Text |  | 选择的菜单项的data属性数据 |
| selectedItem | 选择的菜单项 | Object |  | 选择的菜单项的CommonOperationItem对象 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
