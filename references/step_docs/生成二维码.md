# 生成二维码

- 模块键: `sys:createQrCode`
- 步骤类型: `Action`
- 说明: 将文本转换为二维码
- 帮助: https://getquicker.net/KC/Help/Doc/createqrcode

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:createQrCode",
  "InputParams": {
    "code": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "pixelsPerModule": {
      "VarKey": "",
      "Value": "4"
    },
    "darkColor": {
      "VarKey": "",
      "Value": "#FF000000"
    },
    "lightColor": {
      "VarKey": "",
      "Value": "#FFFFFFFF"
    },
    "icon": {
      "VarKey": "",
      "Value": ""
    },
    "iconPercent": {
      "VarKey": "",
      "Value": "15"
    },
    "iconBorderWidth": {
      "VarKey": "",
      "Value": "6"
    },
    "drawQuietZones": {
      "VarKey": "",
      "Value": "1"
    },
    "saveToPdfPath": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "img": "out_img",
    "svg": "out_svg",
    "ascii": "out_ascii"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| code | 文本 | Text | 是 |  |  | 要转换为二维码的内容 |
| pixelsPerModule | 每模块像素数 | Integer | 否 | 4 |  |  |
| darkColor | 暗色 | Text | 否 | #FF000000 |  | #AARRGGBB格式的颜色值 |
| lightColor | 亮色 | Text | 否 | #FFFFFFFF |  | #AARRGGBB格式的颜色值 |
| icon | 图标 | Image | 否 |  |  | 图片变量或图标文件路径 |
| iconPercent | 图标占比 | Integer | 否 | 15 |  | 百分比数字（只填数字，不写百分号） |
| iconBorderWidth | 图标边框宽度 | Integer | 否 | 6 |  | 最小为1 |
| drawQuietZones | 绘制外框 | Boolean | 否 | 1 |  |  |
| saveToPdfPath | 输出pdf文件 | Text | 否 |  |  |  |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| img | 二维码图片 | Image |  | 生成的二维码图片对象 |
| svg | SVG格式结果 | Text |  | Svg格式结果代码 |
| ascii | Ascii格式结果 | Text |  | Ascii字符格式结果代码 |

## 要点
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
