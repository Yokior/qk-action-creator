# 获取系统路径

- 模块键: `sys:getFolderPath`
- 步骤类型: `Action`
- 说明: 返回指定的特殊目录路径。
- 帮助: https://getquicker.net/KC/Help/Doc/getfolderpath

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:getFolderPath",
  "InputParams": {},
  "OutputParams": {
    "path": "out_path"
  }
}
```

## 输入参数
无。

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| path | 路径 | Text |  | 返回的完整路径 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
