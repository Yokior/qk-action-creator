# 屏幕截图

- 模块键: `sys:screenCapture`
- 步骤类型: `Action`
- 说明: 截取屏幕区域
- 帮助: https://getquicker.net/KC/Help/Doc/screencapture

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:screenCapture",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "select"
    },
    "area": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "windowHandle": {
      "VarKey": "",
      "Value": "0"
    },
    "delay": {
      "VarKey": "",
      "Value": "0"
    },
    "preSelectArea": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "includeRightBottomBorder": {
      "VarKey": "",
      "Value": "true"
    },
    "toClip": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "img": "out_img",
    "rect": "out_rect",
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 截图类型 | Enum | 否 | select | select=选择区域 / full_screen=所有屏幕 / primary_screen=主屏幕 / fixed_area=固定区域 / window=窗口 (屏幕可见内容) / windowBackground=窗口 (支持后台显示) | 截取图片的屏幕区域类型 |
| area | 截图区域 | Text | 否 |  | 仅用于 fixed_area | 要截取的屏幕坐标位置（像素值），格式为：left,top,right,bottom。默认不包含右边和底边像素。 |
| windowHandle | 窗口句柄 | Integer | 否 | 0 | 仅用于 window, windowBackground | 要截取的窗口句柄数字。0或留空表示截取前台窗口。 |
| delay | 截图前延迟时间 | Integer | 是 | 0 |  | 等待多少毫秒后开始截图 |
| preSelectArea | 预选截图区域 | Text | 否 |  | 仅用于 select | 非必要请勿设置。预先选择的截图区域，格式为：left,top,right,bottom。默认不包含右边和底边像素。 |
| includeRightBottomBorder | 预选截图区域包含右边和底边像素 | Boolean | 否 | true | 仅用于 fixed_area, select | 包含时，当指定 0,0,2,2 的时候，截图的大小为3*3, 否则为2*2 |
| toClip | 写入剪贴板 | Boolean | 否 | false |  | 截屏图片是否写入到剪贴板中 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| img | 图片 | Image |  | 截图的图片 |
| rect | 截图区域 | Text |  | 图片的截取区域(left,top,right,bottom)。 |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
