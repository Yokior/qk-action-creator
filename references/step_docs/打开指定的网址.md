# 打开指定的网址

- 模块键: `sys:openUrl`
- 步骤类型: `Action`
- 说明: 打开指定的网址
- 帮助: https://getquicker.net/KC/Help/Doc/openurl

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:openUrl",
  "InputParams": {
    "url": {
      "VarKey": "",
      "Value": "https://"
    },
    "browser": {
      "VarKey": "",
      "Value": "default"
    },
    "exePath": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| url | 网址 | Text | 是 | https:// |  | 要打开的网页地址 |
| browser | 浏览器 | Enum | 是 | default |  | 使用什么浏览器打开网址 |
| exePath | 浏览器程序路径 | Text | 是 |  | 仅用于 custom | 浏览器exe程序路径 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 失败后是否停止动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |

## 要点
- 控制参数: `browser`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
