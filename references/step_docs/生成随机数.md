# 生成随机数

- 模块键: `sys:randomNum`
- 步骤类型: `Action`
- 说明: 生成随机数
- 帮助: https://getquicker.net/KC/Help/Doc/randomnum

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:randomNum",
  "InputParams": {
    "min": {
      "VarKey": "",
      "Value": "0"
    },
    "max": {
      "VarKey": "",
      "Value": "100"
    }
  },
  "OutputParams": {
    "output": "out_output"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| min | 最小值 | Integer | 是 | 0 |  | 随机数范围的最小值（结果大于或等于此值） |
| max | 最大值 | Integer | 是 | 100 |  | 随机数范围的最大值（结果小于此值） |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| output | 随机数 | Integer |  | 生成的随机数 |

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
