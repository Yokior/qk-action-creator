# 列表合并成文本

- 模块键: `sys:joinList`
- 步骤类型: `Action`
- 说明: 将列表拼接为一段文本
- 帮助: https://getquicker.net/KC/Help/Doc/joinlist

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:joinList",
  "InputParams": {
    "list": {
      "VarKey": "",
      "Value": "item1\\nitem2"
    },
    "separator": {
      "VarKey": "",
      "Value": ","
    },
    "escapeSeparator": {
      "VarKey": "",
      "Value": "false"
    }
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| list | 输入 | List | 是 |  |  | 要拼接为文本的列表 |
| separator | 分隔文本 | Text | 是 | , |  | 拼接内容时，两项之间的内容。 |
| escapeSeparator | 转义“分隔文本” | Boolean | 否 | false |  | 替换“分隔文本”中的转义字符（\\r,\\n,\\t） |

## 输出参数
无。

## 要点
- `InputParams.<参数Key>` 值固定为 `{ "VarKey": "", "Value": "..." }`。直接写值用 `Value`，引用变量用 `VarKey`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
