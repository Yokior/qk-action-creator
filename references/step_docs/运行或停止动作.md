# 运行或停止动作

- 模块键: `sys:runAction`
- 步骤类型: `Action`
- 说明: 执行指定的其他动作
- 帮助: https://getquicker.net/KC/Help/Doc/runaction

## 最小 JSON
```json
{
  "StepRunnerKey": "sys:runAction",
  "InputParams": {
    "type": {
      "VarKey": "",
      "Value": "StartAction"
    },
    "actionId": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "onlyCustomMenu": {
      "VarKey": "",
      "Value": "false"
    },
    "inputParam": {
      "VarKey": "",
      "Value": "示例文本"
    },
    "wait": {
      "VarKey": "",
      "Value": "true"
    },
    "debug": {
      "VarKey": "",
      "Value": "false"
    },
    "hideMessage": {
      "VarKey": "",
      "Value": "false"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "true"
    }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "actionTitle": "out_actionTitle",
    "output": "out_output",
    "count": "out_count"
  }
}
```

## 输入参数
| Key | 名称 | 类型 | 必填 | 默认值 | 取值/可见性 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| type | 类型 | Enum | 是 | StartAction | StartAction=运行动作 / StopAction=停止动作 / ShowActionContextMenu=显示动作右键菜单 / StartCurrentAction=运行当前动作（注意避免产生循环或递归） / StopOtherInstance=停止当前动作的其它实例 / GetRunningActionCount=获取动作运行个数（自己编写动作时可用） | 操作类型 |
| actionId | 目标动作 | Text | 是 |  | 仅用于 StartAction, StopAction, ShowActionContextMenu, GetRunningActionCount | 要运行的其他动作的ID或名称(使用名称时需要完全匹配且不能有重名动作) |
| onlyCustomMenu | 仅显示动作的自定义菜单 | Boolean | 否 | false | 仅用于 ShowActionContextMenu | 不显示编辑、复制等菜单 |
| inputParam | 命令参数 | Text | 是 |  | 仅用于 StartAction, StartCurrentAction | 传递给目标动作的参数。存储在该动作的quicker_in_param变量中。 |
| wait | 等待运行结束 | Boolean | 否 | true | 仅用于 StartAction, StartCurrentAction | 是否等待此动作运行结束再执行后续动作（如需获取目标动作的输出，需选中此项） |
| debug | 调试模式运行 | Boolean | 否 | false | 仅用于 StartAction, StartCurrentAction | 是否以调试模式运行动作 |
| hideMessage | 不显示提示消息 | Boolean | 否 | false | 仅用于 StopAction | 仅对非动作库安装的动作有效 |
| stopIfFail | 失败后停止 | Boolean | 否 | true |  | 如果未找到目标动作，是否停止当前动作 |

## 输出参数
| Key | 名称 | 类型 | 可见性 | 说明 |
| --- | --- | --- | --- | --- |
| isSuccess | 是否成功 | Boolean |  | 操作是否成功 |
| actionTitle | 动作名称 | Text | 仅用于 StartAction | 运行的动作名称。 |
| output | 动作输出 | Text | 仅用于 StartAction, StartCurrentAction | 被调用动作的输出。 |
| count | 运行个数 | Number | 仅用于 GetRunningActionCount | 动作正在运行的个数 |

## 要点
- 控制参数: `type`。先定控制参数，再看其余参数是否生效。
- 带 `TextTools` 的参数在编辑器里通常有选择器辅助，但 JSON 本体仍只写 `VarKey` / `Value`。
- `OutputParams.<输出Key>` 的值是变量名字符串，不是对象。
