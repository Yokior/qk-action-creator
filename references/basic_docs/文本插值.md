# 文本插值

- 来源：https://getquicker.net/KC/Help/Doc/interpolation

## 用途

- 用于理解在文本参数里混合固定文本与变量值时，应如何书写。

## 对 qk-action-creator 的直接约束

- 当参数本质上是文本模板时，优先使用插值语法，而不是强行改成表达式。
- 只有参数文档允许文本输入时，才在 `Value` 中写插值文本。
- 插值解决的是“拼文本”，不是“构造任意对象”。
- 如果只是把几个变量和固定文本拼成提示词、标题、路径、消息内容，优先用 `$$`。
- 不要为了简单字符串拼接改用 `sys:csscript`。

## 常用模式

- 提示文本：
  - `$$当前次数：{次数}`
- 多段文本拼接：
  - `$$已处理 {成功数} 项，失败 {失败数} 项`
- 路径模板：
  - `$$D:\\导出\\{文件名}.txt`

## 使用判断

- 用户要在提示文本、输出文本、标题、路径模板里引用变量时，先看这份文档。
- 如果需求不是输出文本，而是要计算布尔值、数字或对象，通常不该先选插值。
