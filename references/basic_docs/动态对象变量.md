# 动态对象变量

- 来源：https://getquicker.net/KC/Help/Doc/object

## 用途

- 用于理解动态对象变量可以承载任意类型的运行时对象。

## 对 qk-action-creator 的直接约束

- 这份文档说明的是运行时使用语义，不直接给出顶层 `Variables` 的完整 JSON 字段结构。
- 只有当步骤输出或后续表达式明确需要“任意对象”时，才考虑把变量类型设为动态对象。
- 顶层变量类型名直接写 `Any`。
- 若步骤文档明确把输入或输出类型写成 `Object`，那是步骤参数或步骤输出语义；顶层 `Variables[].Type` 仍优先写 `Any`，不要自行改写成 `Object`。

## 使用判断

- 用户提到“对象成员”“任意类型”“复杂返回值”时，先看这份文档。
