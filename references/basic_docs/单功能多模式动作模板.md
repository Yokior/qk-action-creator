# 单功能多模式动作模板

## 用途

- 这份文档专门处理“一个动作围绕同一主题，但内部支持多种模式”的场景。
- 典型如 OCR、翻译、转换、提取、发送。

## 适用场景

- 同一入口下有多种模式。
- 各模式共享部分输入或收尾逻辑。
- 不希望为每种模式单独做一个动作。

## 推荐结构

1. 初始化公共变量
2. 获取输入
3. 判断模式来源
4. 分发到各模式子程序
5. 执行公共收尾

## 主流程职责

- 统一获取输入
- 统一判断入口
- 决定进入哪个模式
- 调用对应子程序
- 做统一通知或输出

主流程不负责：

- 某个模式的完整实现细节

## 模式实现职责

- 每个模式放在独立子程序中。
- 模式内部继续按阶段使用 `group`。
- 公共工具流程尽量复用，不要每个模式复制一份。

## 适合的模块组合

- `sys:simpleIf` / `sys:if`
- `sys:subprogram`
- `sys:group`
- `sys:comment`
- 需要时配合 `sys:custompanel` 选择模式

## 对 qk-action-creator 的直接约束

- 当用户需求明显是“同一类能力下多个模式”，不要先平铺多个分支到主流程。
- 默认先抽出：
  - 公共输入段
  - 模式分发段
  - 各模式子程序
  - 公共收尾段

## 典型结构表现

- 同一入口下分出多个模式子程序。
- 主流程统一拿输入，模式内部各自实现。
