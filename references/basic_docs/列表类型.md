# 列表类型

- 来源：https://getquicker.net/KC/Help/Doc/var-list

## 用途

- 用于理解列表变量适合保存一组有顺序的值。

## 对 qk-action-creator 的直接约束

- 当步骤输出是多项文本、文件列表、批量结果时，优先考虑列表变量。
- 不要把“列表的元素操作方式”误解为顶层变量定义字段。
- 若要声明顶层列表变量，直接使用 `references/basic_docs/顶层Variables结构.md` 里的最小结构，并将 `Type` 写为 `List`。

## 使用判断

- 用户提到“多项结果”“循环处理一组值”“文件列表”时，先看这份文档。
