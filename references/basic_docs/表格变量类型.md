# 表格变量类型

- 来源：https://getquicker.net/KC/Help/Doc/tablevar

## 用途

- 用于理解表格变量适合表示二维数据。

## 对 qk-action-creator 的直接约束

- 读取 Excel、数据库查询、多列结果时，可能需要表格变量。
- 表格的列定义、行访问方式属于运行时语义，不等于顶层 `Variables` 的 JSON 字段。
- 若要新增表格变量，直接使用 `references/basic_docs/顶层Variables结构.md` 里的最小结构，并将 `Type` 写为 `Table`。

## 使用判断

- 用户提到“二维表”“行列数据”“DataTable”时，先看这份文档。
