# 参数传递

- 来源：https://getquicker.net/KC/Help/Doc/parameters

## 用途

- 用于理解步骤输入参数如何从固定值、变量、表达式得到最终值。

## 对 qk-action-creator 的直接约束

- `InputParams.<参数Key>` 只有两种直接写法需要优先考虑：
  - 写固定值：`{ "VarKey": "", "Value": "..." }`
  - 引用变量：`{ "VarKey": "变量名", "Value": "" }`
- 只有确认该参数需要表达式或插值时，才把表达式文本写进 `Value`。
- 不要把“参数计算过程”误解为可以自由增删 `InputParams` 结构字段。

## 使用判断

- 用户问“这个参数该写值还是写变量”时，先看这份文档。
- 用户问“参数为什么没有按预期生效”时，也先回到这份文档排查。
