# 词典类型

- 来源：https://getquicker.net/KC/Help/Doc/var-dict

## 用途

- 用于理解词典变量是键值对结构，适合按键读取和写入。

## 对 qk-action-creator 的直接约束

- 当步骤文档要求传入 JSON 风格对象、键值集合或表单数据时，优先考虑词典变量。
- 不要把词典帮助页里的示例操作，误写成顶层 `Variables` 内部字段。
- 若要新增词典类型顶层变量，直接使用 `references/basic_docs/顶层Variables结构.md` 里的最小结构，并将 `Type` 写为 `Dict`。

## 使用判断

- 表单、接口结果、命名参数集合这类需求，先看这份文档。
