# 多字段表单_动态词典配置样例

这份文档用于补足 `sys:form` 在 `dict_dynamic` 模式下的离线可复用样例。

## 适用场景

- 需要维护一组配置项
- 配置项适合收束到一个词典变量
- 字段包含分组、布尔、数字、下拉、显示条件
- 下次运行还要继续复用这组配置

## 推荐结构

1. 初始化默认词典
2. 读取动作状态
3. 若有已保存配置，则载入词典
4. 打开 `dict_dynamic` 表单
5. 保存回动作状态
6. 提示成功
7. `sys:stop`

## 当前样例覆盖点

- 文本输入
- 数字输入
- 布尔输入
- 下拉选择
- 分组
- `VisibleExpression`
- `TextTools`

## 使用规则

- 需要显示条件时，优先写 `VisibleExpression`。
- 需要颜色、文件、文件夹等辅助输入时，优先查 `TextTools` 是否已有成熟写法。
- 若同一组配置后续还要反复使用，表单变量优先用词典，不要散落成很多顶层变量。
