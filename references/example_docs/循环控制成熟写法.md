# 循环控制成熟写法

这份文档用于固化 `each / repeat / break / continue` 的成熟组合方式。

## 适用场景

- 批量处理一组项目。
- 生成菜单项。
- 遍历规则集。
- 对列表逐项做判定和加工。

## 何时优先 `each`

- 已经有列表。
- 需要逐项读取值。
- 处理目标天然就是一组项目。

## 何时优先 `repeat`

- 已知次数。
- 需要按次数重复，不依赖列表输入。

## 何时优先 `break`

- 命中第一项即可停止。
- 后续继续遍历没有意义。
- 已找到目标项。

## 何时优先 `continue`

- 当前项不满足条件。
- 需要跳过当前项继续下一个。
- 不想增加多级嵌套。

## 推荐结构

1. 获取列表
2. `each`
3. 在循环体里做条件判断
4. 不符合时 `continue`
5. 命中后处理
6. 需要提前结束时 `break`

## 最小样例

```json
{
  "StepRunnerKey": "sys:each",
  "InputParams": {
    "list": { "VarKey": "itemList", "Value": null }
  },
  "OutputParams": {
    "item": "currentItem",
    "index": "currentIndex"
  },
  "IfSteps": [
    {
      "StepRunnerKey": "sys:simpleIf",
      "InputParams": {
        "condition": { "VarKey": "", "Value": "$= String.IsNullOrWhiteSpace({currentItem})" }
      },
      "OutputParams": {},
      "IfSteps": [
        {
          "StepRunnerKey": "sys:continue",
          "InputParams": {}
        }
      ]
    },
    {
      "StepRunnerKey": "sys:simpleIf",
      "InputParams": {
        "condition": { "VarKey": "", "Value": "$= {currentItem}.Contains(\"目标\")" }
      },
      "OutputParams": {},
      "IfSteps": [
        {
          "StepRunnerKey": "sys:notify",
          "InputParams": {
            "type": { "VarKey": "", "Value": "Info" },
            "msg": { "VarKey": "", "Value": "$$命中：{currentItem}" }
          }
        },
        {
          "StepRunnerKey": "sys:break",
          "InputParams": {}
        }
      ]
    }
  ]
}
```

## 要点

- `continue` 常用于卫语句，减少多层嵌套。
- `break` 常用于规则命中后立即结束。
- 循环体过长时，应把处理逻辑下沉到子程序。

## 典型适用动作

- 规则遍历型动作。
- 批量处理型动作。
- 逐项判定并可能提前结束的动作。
