# 右键菜单设置入口样例

这份文档用于固化“动作右键菜单已由用户手工创建，后续流程如何接线”的离线样例。

## 前提

- 用户已经在 Quicker 里手工创建了动作右键菜单
- skill 不负责新建 `ContextMenuData`
- 当前工作区约定，菜单入口数据按动作入口参数处理，优先通过 `quicker_in_param` 判定

## 推荐主流程

1. 初始化默认配置
2. 读取已保存状态
3. 若存在状态则回填配置
4. 判断 `quicker_in_param`
5. 若为“设置参数”，进入设置分支
6. 设置分支保存状态、提示、停止
7. 普通点击继续执行主功能

## 硬规则

- 设置入口命中后，保存完成必须停止。
- 不要让设置分支继续落入主功能。
- 若只有入口判断，没有 `else`，优先 `sys:simpleIf`。
- 不要生成空 `ElseSteps`。
