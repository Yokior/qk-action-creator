# 变量与表达式最小样例

这些样例用于回答“变量该怎么建”“简单逻辑该怎么写”。

## 赋值 + `$=`

- 简单计算、成员访问、条件值选择，优先用 `sys:assign`。

```json
{
  "StepRunnerKey": "sys:assign",
  "InputParams": {
    "input": {
      "VarKey": "",
      "Value": "$= {num} + 1"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "1"
    }
  },
  "OutputParams": {
    "output": "num"
  }
}
```

## 赋值 + `$$`

- 文本拼接优先直接写 `$$`，不要先写脚本。

```json
{
  "StepRunnerKey": "sys:assign",
  "InputParams": {
    "input": {
      "VarKey": "",
      "Value": "$$数字是{num}"
    },
    "stopIfFail": {
      "VarKey": "",
      "Value": "1"
    }
  },
  "OutputParams": {
    "output": "varName"
  }
}
```

## 列表

- 顶层变量类型：
  - `List`
- 常见模块：
  - `sys:listOperations`

```json
{
  "StepRunnerKey": "sys:listOperations",
  "InputParams": {
    "list": { "VarKey": "列表", "Value": null },
    "type": { "VarKey": "", "Value": "append" },
    "item": { "VarKey": "", "Value": "1" }
  },
  "OutputParams": {
    "isEmpty": "out_isEmpty",
    "length": "out_length"
  }
}
```

要点：

- 能用列表模块完成，就不要改用脚本。
- 列表是引用类型；若只是原地追加，很多场景不需要再输出回原变量。

## 词典

- 顶层变量类型：
  - `Dict`
- 常见模块：
  - `sys:dictOperations`

```json
{
  "StepRunnerKey": "sys:dictOperations",
  "InputParams": {
    "type": { "VarKey": "", "Value": "setOriginValue" },
    "dict": { "VarKey": "dict", "Value": null },
    "key": { "VarKey": "", "Value": "key1" },
    "value": { "VarKey": "", "Value": "v1" },
    "ignoreCase": { "VarKey": "", "Value": "0" },
    "stopIfFail": { "VarKey": "", "Value": "0" }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "errMessage": "out_errMessage"
  }
}
```

## 表格

- 顶层变量类型：
  - `Table`
- 常见模块：
  - `sys:tableoperation`

```json
{
  "StepRunnerKey": "sys:tableoperation",
  "InputParams": {
    "table": { "VarKey": "table", "Value": null },
    "type": { "VarKey": "", "Value": "addRow" },
    "rowData": { "VarKey": "", "Value": "id:1\r\nname:小李" },
    "stopIfFail": { "VarKey": "", "Value": "1" }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "firstRow": "out_firstRow",
    "rowCount": "out_rowCount",
    "errMessage": "out_errMessage"
  }
}
```

要点：

- 表格本质上对应 C# 的 `DataTable`。
- 字段定义看 `references/basic_docs/表格变量类型.md`，不要凭界面名称猜结构。
