# 流程与结构最小样例

这些样例来自已验证的最小实现，用于补足常见流程结构的离线参考。

## 步骤组

- 适用：
  - 同一阶段的步骤分组
  - 提高可读性
  - 统一折叠、禁用、观察
- 对应模块：
  - `sys:group`

```json
{
  "StepRunnerKey": "sys:group",
  "InputParams": {
    "skipErr": { "VarKey": "", "Value": "0" },
    "skipWhenDebugging": { "VarKey": "", "Value": "0" },
    "useMultiThread": { "VarKey": "", "Value": "0" },
    "waitAny": { "VarKey": "", "Value": "0" }
  },
  "OutputParams": {
    "isSuccess": "out_isSuccess",
    "errorMessage": "out_errorMessage"
  },
  "IfSteps": [
    {
      "StepRunnerKey": "sys:assign",
      "InputParams": {
        "input": { "VarKey": "", "Value": "1" },
        "stopIfFail": { "VarKey": "", "Value": "1" }
      },
      "OutputParams": {
        "output": "num"
      }
    }
  ],
  "ElseSteps": []
}
```

要点：

- 步骤组本身放在 `Steps` 中。
- 组内步骤写在 `IfSteps`。
- 仅为了结构分段时，优先用步骤组，不要强行拆子程序。
- 关键阶段优先配合 `sys:comment` 注释模块说明业务语义。

## 如果 / 否则

- 仅有 `if`：
  - `sys:simpleIf`
- 有 `if` 和 `else`：
  - `sys:if`

```json
{
  "StepRunnerKey": "sys:if",
  "InputParams": {
    "condition": {
      "VarKey": "",
      "Value": "$= String.Equals({text}, \"aaa\", StringComparison.OrdinalIgnoreCase)"
    }
  },
  "OutputParams": {},
  "IfSteps": [
    {
      "StepRunnerKey": "sys:notify",
      "InputParams": {
        "type": { "VarKey": "", "Value": "Info" },
        "msg": { "VarKey": "", "Value": "text 是 aaa" }
      },
      "OutputParams": {}
    }
  ],
  "ElseSteps": [
    {
      "StepRunnerKey": "sys:notify",
      "InputParams": {
        "type": { "VarKey": "", "Value": "Info" },
        "msg": { "VarKey": "", "Value": "text 不是 aaa" }
      },
      "OutputParams": {}
    }
  ]
}
```

要点：

- 条件优先直接写 `$=` 表达式。
- `IfSteps`、`ElseSteps` 放完整步骤对象，不是字符串。
- 没有 `else` 时，不要生成 `sys:if + 空 ElseSteps`。
- 需要提前结束时，优先在 `IfSteps` 中直接接 `sys:stop`，减少嵌套。

## 重复

- 对应模块：
  - `sys:repeat`
- 用于计数循环或带终止条件的重复执行。

```json
{
  "StepRunnerKey": "sys:repeat",
  "InputParams": {
    "count": { "VarKey": "重复次数", "Value": null },
    "stopCondition": { "VarKey": "中止条件", "Value": null },
    "startIndex": { "VarKey": "计数开始值", "Value": null },
    "repeatDelayMs": { "VarKey": "循环间隔时间毫秒", "Value": null },
    "progressBarTitle": { "VarKey": "进度条标题", "Value": null }
  },
  "OutputParams": {
    "count": "index"
  },
  "IfSteps": [
    {
      "StepRunnerKey": "sys:notify",
      "InputParams": {
        "type": { "VarKey": "", "Value": "Info" },
        "msg": { "VarKey": "index", "Value": null }
      },
      "OutputParams": {}
    }
  ]
}
```

要点：

- 循环体也写在 `IfSteps`。
- 需要 `break`、`continue` 时，分别使用独立步骤 `sys:break`、`sys:continue`。

## 子程序

- 顶层：
  - `SubPrograms`
- 调用步骤：
  - `sys:subprogram`

```json
{
  "SubPrograms": [
    {
      "Name": "测试子程序",
      "Variables": [
        { "Key": "输入变量", "Type": 0, "IsInput": true, "IsOutput": false },
        { "Key": "输出变量", "Type": 0, "IsInput": false, "IsOutput": true }
      ],
      "Steps": [
        {
          "StepRunnerKey": "sys:assign",
          "InputParams": {
            "input": { "VarKey": "", "Value": "$$123{输入变量}123" }
          },
          "OutputParams": {
            "output": "输出变量"
          }
        }
      ]
    }
  ]
}
```

调用最小样例：

```json
{
  "StepRunnerKey": "sys:subprogram",
  "InputParams": {
    "subProgram": { "VarKey": "", "Value": "测试子程序" },
    "var:输入变量": { "VarKey": "", "Value": "999" },
    "stopIfFail": { "VarKey": "", "Value": "1" },
    "skipDebugOutput": { "VarKey": "", "Value": "false" },
    "summary": { "VarKey": "", "Value": "" }
  },
  "OutputParams": {
    "var:输出变量": "输出变量"
  }
}
```

要点：

- 可复用逻辑优先抽成子程序。
- 子程序输入输出变量依赖 `IsInput`、`IsOutput`，普通顶层变量不要滥用这两个标记。

## 配置型动作的主流程模板

- 适用：
  - 有“设置参数”入口
  - 配置下次运行还要继续使用
  - 主功能与设置入口共用同一组配置

推荐结构：

1. `sys:comment`
   - 注释“初始化默认配置”
2. 初始化默认配置变量
3. `sys:comment`
   - 注释“读取已保存配置”
4. `sys:stateStorage`
   - 读取动作状态
5. `sys:simpleIf`
   - 状态非空则回填配置
6. `sys:comment`
   - 注释“判断入口”
7. `sys:simpleIf`
   - 判断 `quicker_in_param`
8. 设置分支中：
   - 打开表单
   - 保存状态
   - 提示成功
   - `sys:stop`
9. 主功能分支继续执行

要点：

- 主流程优先做编排，不要把表单、状态、主逻辑糊成一团。
- 设置入口命中后，必须停止，不要再继续主功能。
