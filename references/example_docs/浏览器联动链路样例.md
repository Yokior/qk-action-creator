# 浏览器联动链路样例

这份文档用于固化涉及 `sys:chromecontrol` 的常见动作链路。

## 适用场景

- 需要读取浏览器上下文。
- 需要控制页面元素。
- 需要根据网址或页面状态做后续动作。

## 推荐链路一：读取网址 -> 判断规则 -> 执行动作

1. 获取当前网址
2. `sys:simpleIf` / `sys:if`
3. 命中后调用子程序

## 推荐链路二：打开页面 -> 等待元素 -> 执行页面动作

1. `sys:chromecontrol`
   - `operation=OpenUrl`
2. `sys:chromecontrol`
   - 等待目标元素
3. `sys:chromecontrol`
   - 输入、点击、提取

## 推荐链路三：浏览器上下文 -> 生成操作项

1. 读取网址或页面信息
2. 进入规则判定
3. 构造操作项列表
4. `sys:custompanel`

## 要点

- 先判断浏览器控制是不是必要，不要把普通网页打开误做成浏览器自动化。
- 只要进入浏览器联动场景，优先把上下文获取与页面动作分开。
- 多行脚本文本时，按已有规则写 `\r\n`。

## 典型适用动作

- 需要读取浏览器上下文的动作。
- 需要按网址或页面元素分发的动作。
- 需要从浏览器联动到操作面板的动作。
