# 文件与剪贴板处理链路样例

这份文档用于固化文件处理与剪贴板处理中最常见的跨模块链路。

## 样例一：选中文件 -> 读取内容 -> 处理 -> 写回

### 推荐链路

1. `sys:getSelectedFiles`
2. `sys:pathExtraction`
3. `sys:readFile`
4. 文本处理模块
5. `sys:WriteTextFile`

### 适用场景

- json 格式化
- 文本批量替换
- 配置文件加工

## 样例二：读取剪贴板 -> 判断 -> 处理 -> 写回

### 推荐链路

1. `sys:getClipboardText`
2. `sys:simpleIf` / `sys:if`
3. 文本处理或转换模块
4. `sys:writeClipboard`
5. `sys:notify`

### 适用场景

- 文本格式化
- 转义 / 去转义
- OCR 结果二次加工

## 样例三：文件路径 -> 派生输出路径 -> 保存结果

### 推荐链路

1. `sys:pathExtraction`
2. `sys:assign`
3. `sys:WriteTextFile` 或 `sys:fileOperation`

### 要点

- 输出路径优先先算清楚，再进入写入步骤。
- 不要把路径拼接逻辑分散在多个步骤参数里。

## 对 qk-action-creator 的直接约束

- 需求涉及文件处理时，优先先画出链路，不要直接挑单个模块。
- 需求涉及剪贴板读写时，默认要判断是否需要在结尾回写剪贴板并提示。
- 跨模块链路里，路径和中间文本优先显式建变量。

## 典型适用动作

- 文本格式化类动作。
- 剪贴板加工类动作。
- 文件转换与文件中转类动作。
