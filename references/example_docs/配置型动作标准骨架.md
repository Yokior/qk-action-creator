# 配置型动作标准骨架

这份文档用于固化“有设置入口、需要长期保存配置”的动作骨架。

## 适用场景

- 需要维护一组配置项。
- 下次运行还要继续使用这组配置。
- 同一动作既支持主功能，也支持设置入口。

## 推荐主流程

1. 初始化默认配置
2. 读取动作状态
3. 若非空则回填配置
4. 判断入口参数
5. 命中设置入口则进入设置分支
6. 设置分支保存状态、提示、停止
7. 普通入口继续执行主功能

## 最小骨架样例

```json
[
  {
    "StepRunnerKey": "sys:comment",
    "InputParams": {
      "note": { "VarKey": "", "Value": "初始化默认配置" }
    },
    "OutputParams": {}
  },
  {
    "StepRunnerKey": "sys:comment",
    "InputParams": {
      "note": { "VarKey": "", "Value": "读取动作状态" }
    },
    "OutputParams": {}
  },
  {
    "StepRunnerKey": "sys:stateStorage",
    "InputParams": {
      "type": { "VarKey": "", "Value": "readActionState" },
      "key": { "VarKey": "", "Value": "config" },
      "inputIfEmpty": { "VarKey": "", "Value": "0" },
      "prompt": { "VarKey": "", "Value": "" }
    },
    "OutputParams": {
      "value": "configJson",
      "isEmpty": "configIsEmpty"
    }
  },
  {
    "StepRunnerKey": "sys:simpleIf",
    "InputParams": {
      "condition": { "VarKey": "", "Value": "$= {configIsEmpty} == false" }
    },
    "OutputParams": {},
    "IfSteps": [
      {
        "StepRunnerKey": "sys:comment",
        "InputParams": {
          "note": { "VarKey": "", "Value": "这里回填配置" }
        },
        "OutputParams": {}
      }
    ]
  },
  {
    "StepRunnerKey": "sys:simpleIf",
    "InputParams": {
      "condition": {
        "VarKey": "",
        "Value": "$= String.Equals({quicker_in_param}, \"设置参数\", StringComparison.OrdinalIgnoreCase)"
      }
    },
    "OutputParams": {},
    "IfSteps": [
      {
        "StepRunnerKey": "sys:form",
        "InputParams": {
          "operation": { "VarKey": "", "Value": "dict_dynamic" },
          "dictVar": { "VarKey": "configDict", "Value": null },
          "title": { "VarKey": "", "Value": "设置参数" },
          "dynamicFormForDictDef": { "VarKey": "", "Value": "{\"Fields\":[]}" },
          "stopIfFail": { "VarKey": "", "Value": "1" }
        },
        "OutputParams": {
          "button": "formButton"
        }
      },
      {
        "StepRunnerKey": "sys:stateStorage",
        "InputParams": {
          "type": { "VarKey": "", "Value": "saveActionState" },
          "key": { "VarKey": "", "Value": "config" },
          "value": { "VarKey": "configDict", "Value": null }
        },
        "OutputParams": {}
      },
      {
        "StepRunnerKey": "sys:notify",
        "InputParams": {
          "type": { "VarKey": "", "Value": "Success" },
          "msg": { "VarKey": "", "Value": "配置已保存" }
        }
      },
      {
        "StepRunnerKey": "sys:stop",
        "InputParams": {}
      }
    ]
  }
]
```

## 要点

- 设置入口命中后，默认应停止，不继续主功能。
- 配置优先统一读，不要分散到多个分支重复读取。
- 配置若是一组字段，优先收束为词典。

## 典型适用动作

- 带设置入口的配置型动作。
- 主功能与参数维护共存的动作。
