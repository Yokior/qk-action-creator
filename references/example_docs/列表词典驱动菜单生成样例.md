# 列表词典驱动菜单生成样例

这份文档用于固化“先组织数据，再生成菜单或操作项”的成熟路径。

## 适用场景

- 操作集合面板
- 动态菜单
- 规则命中后生成一组动作项

## 推荐结构

1. 初始化操作项列表
2. 准备规则或数据源
3. 遍历数据源
4. 每项组装标题、图标、数据、动作方式
5. 追加到操作项列表
6. 最后整体显示

## 推荐容器

- 外层：
  - 列表
- 每项：
  - 词典或 `operationData` 对象

## 推荐模块组合

- `sys:listOperations`
- `sys:dictOperations`
- `sys:each`
- `sys:assign`
- `sys:custompanel`

## 最小思路

- 列表负责顺序。
- 词典负责字段语义。
- `custompanel` 最后一次性吃进完整结构。

## 要点

- 不要边遍历边直接拼最终大文本，优先先组织结构化项。
- 图标优先 `fa:`。
- 需要点击后运行子程序时，明确写 `Operation` 与 `SpName`。

## 典型适用动作

- 动态操作项生成类动作。
- 面板式操作集合动作。
- 模式驱动的操作入口动作。
